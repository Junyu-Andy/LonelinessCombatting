## 2. 排查发现的三个问题

1. **星期日 10/18 的日历周横幅**。V2 关着时 PILOT 老人第 3 天就会在 App 里看到 Weekly PR 和 PGIC 横幅并收到广播，这不在方案的时间表里，会多出一次 Weekly PR 记录。要么 10/18 20:00 前打开 `weeklyScheduleV2Enabled`，要么接受并在试跑记录写明。
2. **两套 Brief PR 并存**。今天装机如果 `sessionBriefPrV2Enabled` 还关着，PILOT 前几天的 Brief PR 是旧弹窗（schemaVersion 2），之后再开就有两种记录格式，分析脚本要分开读。#82 已把按钮和 S10b 定稿接入，T46 已合，技术上今天就能开。
3. **每日广播不分登记状态**。19:00 广播发给所有装了 App 的设备，包括团队和未登记的人；对老人没有影响，但 10/19 开门后未登记账号也会被叫进来看到等待页。可接受，记下即可。
