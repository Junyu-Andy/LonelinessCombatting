# 0023：规则组小欣签到、阿珍/阿伯回忆提交后，按心情从模板池给一条回应（开关默认关）

- 日期：2026-10-07
- 状态：提议中（代码已合并到开关后面，开关默认关；模板正文、心情分档、回忆页是否必选心情等待研究侧定）
- 影响范围：phase_b × 规则组（签到 B、回忆 B）；Hybrid 组不变
- 相关代码：`lib/features/rule_replies/`、`check_in_arm_b.dart`、`reminiscence_arm_b_page.dart`（T15，分支 `feat/rule-based-replies`）

## 背景

规则组里只有通通有「老人输入 → 陪伴者回应」这一步（决策 0005）。小欣 B 提交后只显示一句固定的「收到喇。聽日再見。」；阿珍 B 提交后直接关掉页面，什么回应都没有（T1 审计 C02-R，`docs/spec/audit-20261006.md`）。研究侧希望三个陪伴者在规则组里都有这一步，和 Hybrid 组的交互结构对齐。规则组不能调用 LLM。

## 决定

- **回应从固定模板池选，规则写死**：陪伴者 × 主题 × 心情档 → 一个子池；子池里按顺序选第一条「最近 N 次没出现过」的；全都出现过就选最久之前出现的那条。N 默认 3。不调用任何 LLM，不引用老人写的内容。
- **心情**：用两组已有的 5 个心情脸（`MoodFacePicker`，好差 / 差 / 麻麻地 / 幾好 / 好好）。
  - 小欣 B 本来就要求选心情脸，不加新输入。
  - 阿珍 B 本来没有心情输入；开关开时在输入框下方加同一个心情脸，**选填**。没选时用「未选心情」子池。
  - 5 档先归成 3 个子池档（差 1–2 / 中 3 / 好 4–5），减少研究侧要写的条数。映射表在模板文件里，改成 5 档只改数据。
- **主题**：小欣 = 签到（一个主题）；阿珍 = 每周回忆主题 w1–w4。
- **先过安全检测**：回应前对老人写的文字做安全检测。命中 moderate（review 或 interrupt）或 acute，**不出模板回应**，按现有安全流程走（危机页 / 支援底板 / 写 `safety_events` 通知 PI）。检测调用集中在一个函数里，T7 的统一入口合并后改成调用它。
- **样式**：回应气泡和 Hybrid 组同一页面的陪伴者气泡一样（签到：`surfaceContainerHighest`；回忆：`secondaryContainer`；圆角 18，字号 17）。
- **开关**：编译开关 `RULE_TEMPLATE_REPLIES`，默认关。模板里只要还有占位文字，正式包即使开了开关也不生效，除非另加 `RULE_TEMPLATE_REPLIES_ALLOW_PLACEHOLDER=true`（只用于截图、测试）。
- **最近出现记录**：存 `users/{uid}/rule_reply_history/{agentId}`（`recent`：最近 N 条模板编号）。读不到（离线、未登录）就当没有记录。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 按老人写的关键词选模板（像通通） | 签到备注是选填，常常为空；回忆的关键词表要另写一套。研究侧定的是按心情 |
| 心情直接 5 档各一个子池 | 研究侧要写的条数多一半；先 3 档，数据格式支持随时改 5 档 |
| 回忆页心情必选 | 多一步强制操作，会影响回忆的提交量；先选填，交研究侧定 |
| moderate_review（回忆里常见的哀伤内容）照常给模板 | 任务要求命中安全内容就不给模板；先按最保守的做，交研究侧定 |
| 最近记录存在手机本地 | App 没有本地存储依赖；用户子集合已有读写权限，不用改 Firestore 规则 |

## 后果

- 对研究：
  - 规则组签到、回忆多了一条陪伴者回应，交互结构和 Hybrid 组更接近；开关打开前要定稿模板正文和文化审阅。
  - 回忆 B 多一个心情选择，Hybrid 回忆没有。这是两组界面的新差别，要写进 Methods。
  - 开关打开的日期要写进 STUDY_CHANGELOG；已入组的规则组参与者会在研究中途看到变化，需要研究侧决定是否只对新 cohort 打开。
  - 模板回应会记进 `turns`（`llmStatus: rule_based`），模板编号记在分析事件 `rule_template_reply`。
- 对开发：新增 `lib/features/rule_replies/`（模板池、选择器、最近记录、安全检测入口、气泡）；签到 B、回忆 B 在开关后面接入。T7 合并后把安全检测函数改成调用统一入口。
- 对论文：Methods（规则组干预内容）；如果研究中途打开，Limitations 要提一句。
