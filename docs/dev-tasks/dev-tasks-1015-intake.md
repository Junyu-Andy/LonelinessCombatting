共同规则：(1) 不推 main，只开 PR 草稿；(2) 不碰生产数据，只用 emulator 和合成数据；(3) 新行为放在开关后；(4) 老人看得到的文字只写草稿；(5) 不改热线号码。

## 背景

注册后的「入組問卷」（`lib/features/onboarding/presentation/pages/intake_flow_page.dart`，6 页，`IntakeResponse`）要老人在手机上答约 10–15 分钟，多选题多、自由输入多，10/15 第一位 PILOT 老人做得很吃力。这份问卷的答案只用来给陪伴者做个人化（`intake_memory_seeder.dart` 给三位陪伴者的首次记忆、`profile.interests` 给通通、`closeContacts` 给小欣和行动计划、`avoidTopics` 进提示词作禁区）。Junyu 10/15 定：(1) 题目精简到老人口头能答完的程度；(2) 由研究员在 W0 面访时问，在后台替老人录入；老人的 App 不再出现这一段。两组相同。

## 0. 先答，再动手（写进 docs/dev-reports/）

1. `IntakeResponse` 每个字段现在被谁读：按字段列出读取方（seeder、通通、小欣、行动计划、提示词、导出）。没有读取方的字段可以直接删。
2. 规则组用不用 intake 的任何字段？（模板回应、配对、行动计划）答案决定“两组相同”怎么写进登记表。
3. 登记页现在要研究员“选配对（阿珍／阿伯）”，是不是只为了让登记记录和老人在引导里的选择一致？能不能改成登记时直接读老人资料里的 `ahJanAhBakVariant`，研究员不再选？老人自己选的才算，研究员只记录（10/15 第 10 条 (3)）。
4. 老人已经做过的旧 6 页问卷数据（三位 PILOT）怎么并存：新结构是旧结构的子集就不用迁移，报告里说明。

## 2. 要做的事

1. **后台录入页**（SPEC:C19）。登记页（`unblinded`）多一个「入組資料」区，研究员输入老人的登入电邮或研究编号后填第 1 节五题，提交写 `users/{uid}/intake`（同一 `IntakeResponse` 结构，只填保留字段，`completedParts` 全标、`allCompleted = true`）、`users/{uid}.hasCompletedIntake = true`、`interests`、`closeContacts`、`avoidTopics`，并记一条审计日志（谁、何时、哪个研究编号）。只有 `unblinded` 能调用；规则用 callable 走服务器，客户端不直接写别人的文档。
2. **老人端跳过**。开关 `researcherIntakeEnabled`。开着时 `ConsentGate` 不再弹 `IntakeFlowPage`；若研究员还没录入，老人进主页照常，陪伴者按“没有 intake”处理（seeder 返回 null），研究员录入后下一次打开生效。关着时一切如旧。
3. **精简老人端问卷**（备用）。`IntakeFlowPage` 也按第 1 节减到五题一页，供开关关着时用；这是老人看得到的文字，只写草稿，用词与第 1 节一致。
4. **配对**。按第 0 节第 3 题的答案，登记页去掉研究员选配对，改为显示老人已选的那位（只读）；老人没选时显示「未揀」。
5. **登记表**。C19 加研究员录入；个人化问卷条目改为五题并注明两组相同；配对条目改为“老人在引导里自选，研究员只记录”。
6. **W0 流程**。`docs/release/w0-install-script.md` 第三节顺序 A 的第 6 步改为“研究员口头问五题、后台录入”，第 7 步配对由老人自己选。文字草稿交产品窗口写进 B20 第 7 节。

## 3. 验收（emulator，合成数据）

1. 开关开：新老人注册并走完引导，没有出现入组问卷页；研究员录入五题后，Hybrid 组老人下次打开，小欣首次记忆含目标和一位重要的人，通通的兴趣含所选活动；`avoidTopics` 出现在提示词禁区。
2. 开关开、研究员未录入：老人能正常进主页和聊天，seeder 不写记忆。
3. 开关关：老人端出现五题一页的精简问卷，答完 `hasCompletedIntake = true`。
4. 规则组老人：录入后行为与之前一致（第 0 节第 2 题的答案决定断言）。
5. `blinded` 和参与者账号调用录入函数被拒；审计日志有记录。
6. 旧 6 页数据的三位 PILOT 账号读取不报错。
7. 登记页不再要求研究员选配对；老人在引导里选的变体正确显示。
