## 3. 要带回研究侧的发现

1. **`sessionBriefPrV2Enabled` 放错了文档。** 10/15 中午它被写进 `app_config/feature_flags`，但代码（`PhaseBConfig`）只读 `app_config/phase_b`，1014e 第 1 节第 3 条也写的是 `phase_b`。现在它**没生效**。改法：在 `app_config/phase_b` 加 `sessionBriefPrV2Enabled: true`，`feature_flags` 里那条删掉（留着没害处，但会误导）。
2. **`feature_flags` 里只有这一条。** 第 1 节第 3 条要的 `onboardingAfterEnrollmentFix = true`、`voiceInputEnabled = true`、`usageEventsEnabled = true`，以及 10/15 早上说直接开的 `opsDashboardEnabled = true`，都还没设。`enrollmentGateEnabled`、`assessorViewEnabled` 按计划先不设。
3. **第 19 条的排查清单文件不在仓库里。** `claude/通知与问卷排查-1015.md` 和 `claude/app-icon-prompt-1015.md` 是产品窗口的文件，要 Junyu 发过来才能跑 A1–A15 和做图标。
4. 第 14 条 Push 能力已随 #94 合并；锁屏收到 Firebase 测试消息这一步要 Junyu 在 iPhone 上做。
