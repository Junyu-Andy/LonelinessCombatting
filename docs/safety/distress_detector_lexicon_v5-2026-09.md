## Change v4 → v5 (S-1, S-7)

* The 67 v4 `moderate` terms are split into **moderate_review** (19 — loss / grief + past hardship; LLM replies, nothing surfaced, logged for weekly review) and **moderate_interrupt** (48 — hopelessness, burden / worthlessness cognitions, nobody-cares, overwhelmed, bare 想死; LLM replies **plus** the per-agent template and the soft support sheet).
* Check order is **acute → moderate_interrupt → moderate_review → low → none**, first hit wins. A message containing both 冇人理我 (interrupt) and 過世 (review) routes to interrupt.
* Every term now carries a `category` written to `turns.detector.category` (ideation / worthlessness / self_harm / harm_to_others / loss_grief / hardship / distress / low).
* **S-7** 絕望 family (`冇晒希望`, `沒晒希望`, `無晒希望`, `没有希望`) is a configuration slot: currently `moderate_interrupt` (PI clinical sign-off pending). Flipping `hopelessnessTier` in the detector moves them with no other code change.
* Acute terms, acute short-circuit and the 24 h notification path are unchanged from v4.

## Matching

Lower-cased substring `contains` over the whole message. No negation / sarcasm handling. Same detector in both arms.
