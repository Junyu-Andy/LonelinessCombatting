## 1. 安全内容不进任何一层记忆

- **用 App 同一份词库**：`functions/safety_lexicon.json` 由 App 的 `DistressDetector.lexicon`（`lib/core/safety/distress_detector.dart`）生成，服务器用 `functions/safety_lexicon.js` 读它，匹配方法照抄 App（转小写、按顺序找子串、第一个命中为准）。
- **保证两边一致**：
  - `test/safety_lexicon_export_test.dart`：JSON 和 Dart 词库逐条不一致就失败。改了词库要跑 `UPDATE_SAFETY_LEXICON=1 flutter test test/safety_lexicon_export_test.dart` 重新生成。
  - `test/fixtures/safety_lexicon_cases.json`：17 句例句，App（同一个 Dart 测试）和服务器（`functions/test/safety_lexicon_test.js`）都要得出同一档、同一个命中词。
- **规则和 App 一样**：moderate（两档）或 acute 算命中，就是 App 写 `safety_events`、不进缓冲区的那几档（`DistressMatch.isEscalation`）。
- **命中后**（`functions/memory.js` `screenTurns`）：那一轮老人原话和陪伴者的回复不发给模型，也不存进 `mem_extractions`（`claimBuffer` 就先去掉）；这次会话不写摘要；其他轮次的事实照常抽取。
- **词库认不出的隐晦说法**（例如 D17「我啲安眠藥儲埋咗好多粒，有時諗住一次過食晒佢」，App 词库是 `none`）：抽取 prompt v2 让模型另报 `safety_concern`。为 true 时不写摘要，敏感的事实和跟进也不写。两轮 D17 都由它挡下。**这是模型判断，不是规则**，见第 7 节。
- **服务器原来的 17 个词保留**，仍查模型写出来的事实、跟进、摘要；摘要另外再用 App 词库查一次。
- 注意：moderate_review 包括「過咗身」「好辛苦」这类丧亲、辛苦的说法。App 本来就不把这些轮次放进缓冲区（决策 0013），服务器现在和它一致，所以这些内容也不会进记忆（见 6.3）。

## 2. 摘要里的敏感内容：选「不写进摘要」

- 抽取 prompt v2 要求摘要只写中性日常内容，敏感内容放进事实并标敏感（事实仍走「先确认」）。
- 服务器再判一次：摘要按敏感规则判为敏感就整条不存（`validateExtraction`，`omitSensitiveSummary`）。以前存下的敏感摘要不再注入（`selectForInjection`）。
- 敏感词表加了健康、丧亲、情绪类词（`SENSITIVE_TERMS`，如「中風」「輪椅」「眼矇」「瞓唔着」「走咗」「骨灰」「喊」）。加词只会让更多事实等确认、更多摘要不存。第 1、2 轮里漏掉的「腳唔好」「瞓唔着」「中風」「眼矇」「豆豆走咗」在第 3、4 轮都挡下了。
- 为什么不选「先确认」：要在「我記得嘅嘢」页面加新的界面和文字（老人看得到，要先定稿）；「不写」更简单也更保守。
- 结果：第 3、4 轮存下的摘要 11 条、12 条，人工逐条对过原话，无编造、无安全内容；敏感内容第 3 轮有 1 条边界情况（D30「有少少擔心」，轻度情绪，按保守口径算），第 4 轮 0 条。

## 3. 「唔好記住」

**识别**（`functions/memory_forget.js`，词表版本 `forget-v1-2026-10`）：只看老人自己的话，去掉空格后按规则匹配。

| 类型 | 覆盖的说法（例） |
|---|---|
| 唔好记 | 唔好記住、唔好記低、唔好記錄、唔好記落、唔好記入、不要記住、別記住（前面可加「幫我」「再」） |
| 唔使记 | 唔使記（住／得）、唔駛記、唔洗記、不用記、毋須記 |
| 当我冇讲过 | 當我冇講過、就當我無講過、當冇講過、當我沒說過、當你冇聽過 |
| 唔好话畀人知 | 唔好話畀／俾其他人知、唔好話俾美玲知、唔好同其他人講、唔好講出去、唔好傳出去 |
| 保密 | 幫我保密、你知我知、你知就得、係秘密嚟 |
| 忘记／删除 | 忘記佢、刪咗佢、刪除呢件事、唔好再提呢件事、唔好提起佢 |
| 英文 | don't remember / record / tell anyone、forget it / what I said、keep it secret、off the record |

**不算请求的相似说法**（先去掉再匹配）：唔好記性、記性唔好、唔好記錯、唔使記掛、唔記得、記唔住、講笑、講大話、提醒。不用「咪」：「你咪記住佢囉」意思相反。

**边界**：
- 转述（「個女叫我唔好話畀人知」）也算请求：删多一点是安全的一边。
- 否定句（「唔係叫你唔好記住」）识别不了，会当成请求。
- 只看同一次会话；下一次会话才说「上次嗰件事唔好記住」，只能靠下面的「关联删除」。

**识别到之后**：
- 这次会话**整段不记**：不调用模型，不写摘要、事实、跟进，原话也清掉（`mem_extractions.outcome = forget_request`）。
- **删除相关的旧条目**：任何陪伴者以前存的事实、跟进、摘要，和请求那句（去掉请求词）及前一句老人原话有 2 个以上相同的两字片段（去掉「呢件」「件事」等常见片段）就删除；删掉的事实或跟进，其来源会话的摘要也删除。按字面判断，可能删多，也可能漏删。
- **陪伴者的确认句只写了草稿**：开关 `forgetAckReply` 默认关。文字放在 `functions/prompts/memory_forget_ack.v1.txt`，现在是占位「【待研究側定稿】」；占位没换掉之前，开关打开也不生效。草稿供研究侧参考：
  - 「好，呢件事我唔會記住。」
  - 「明白，我唔記低，你放心。」
