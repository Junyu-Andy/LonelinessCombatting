# 0060：老人注册后先停在等候页，研究员讲解完在屏幕正中 2 秒内连点 3 下才进入组问卷

- 日期：2026-10-20
- 状态：提议中
- 影响范围：phase_b、pilot × 两组（同一页、同一流程）；开关打开后新注册、还没做完引导的帐号
- 相关代码：分支 `claude/zealous-fermat-8rgqtg-intake-gate`；`lib/features/onboarding/presentation/researcher_intake_gate.dart`、`lib/features/consent/presentation/consent_gate.dart`、`lib/core/feature_flags/remote_feature_flags.dart`、`firestore.rules`

## 背景

1020e 第二节第 14 条：W0 面访时，老人注册完、按了「開始之前」就直接进入组问卷，研究员还没来得及讲解研究和 App 怎样用。要让 App 停一下，等研究员讲完再继续；两组要完全一样，不能给老人看到按钮或提示（免得老人自己按过去）。

## 决定

1. 新开关 `app_config/feature_flags.researcherIntakeGateEnabled`（**默认关**，只认布尔 `true`）。关着时流程不变。
2. 开着时，「開始之前」之后、入组问卷之前（五题页；`researcherIntakeEnabled` 开时是「生命中重要嘅人」页）加一页等候页，只有一句「請等研究人員同你講解，再繼續。」（草稿），没有按钮、提示，读屏软件也没有可按的东西。
3. 研究员在屏幕正中（九宫格正中一格：宽、高各中间三分之一）2 秒内连点 3 下（第 1 下到第 3 下 ≤ 2 秒）就进入问卷。别处的点击不算，也不清零。
4. 解锁时间写 `users/{uid}.intakeGateUnlockedAt`，服务器时间。Firestore 规则只许老人自己的帐号写一次、只许服务器时间，不能改、不能删。App 保存资料时不带这个字段。
5. 没解锁前每次打开 App 都回到等候页；解锁后不再出现。已经做完「介紹三個夥伴」的帐号（T37 的完成标记，或 T37 之前做完的痕迹）永远不出现。
6. 开关还没读到时（网络慢）不跳过：先「等一陣…」并在后台重读，8 秒后仍读不到就显示等候页（研究员可放行），读到「关」再自动进问卷。重读失败不会把已读到的值改回关。
7. 讲解稿不进 App。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 等候页放一个「研究員繼續」按钮，或要输密码 | 1020e 要求不显示任何按钮或提示；老人会自己按 |
| 由研究员在登记页远程放行（服务器标记） | 要研究员手机另外操作、老人要重开 App 才生效；现场连点三下更直接 |
| 点哪里都算，只看次数 | 老人等得不耐烦随手连点就会过去 |
| 只认很小的正中一点 | 研究员难点中；九宫格正中一格够大又只占九分之一 |
| 开关读不到就当关（直接进问卷） | 1020e 要求研究员先讲解；网络慢时宁可多等几秒，研究员仍能放行 |
| 等候页放在「開始之前」之前 | 1020e 写的是「不再直接出入组 5 题」；「開始之前」只有一个「繼續」，放在它后面最贴近原意。要提前只改一处，待 Junyu 定 |

## 后果

- 对研究：两组同一页、同一流程，不影响组间对等；不调用 LLM；不改问卷内容和字段。入组流程多一步，开关应在第一位 `PB-` 参与者注册前定好、之后不改，并写进 W0 操作步骤（`docs/release/w0-install-script.md`，产品窗口改）。`intakeGateUnlockedAt` 不进导出。
- 对开发：新开关一个、新字段一个、规则一条、页面一个；测试 `test/researcher_intake_gate_test.dart`、`test/rules/intake_gate_rules.test.js`。
- 对论文：方法部分 W0 流程可写一句「研究员讲解后才开始 App 内的入组问卷」；无局限需加。
