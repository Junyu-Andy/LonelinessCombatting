# 0010：记忆保留到研究结束后 3 年

> 补记（2026-10-04）：这个决定当时在对话里做出，代码已合并。按模板补写，内容以当时的讨论为准。

- 日期：2026-10-01
- 状态：已采纳
- 影响范围：所有 cohort × Hybrid 组
- 相关代码：PR #25（`tool/delete_memory.js`）

## 背景

ICF 需要写明记忆存多久。

## 决定

研究结束后 3 年，用 `tool/delete_memory.js --all --confirm` 删除全部记忆（v0 + v1，含注入日志和抽取记录）。参与者退出时按其要求单独删除。研究数据（对话、问卷、安全事件）不在这个脚本的范围内。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 退出时立即删除 | 负责人选择按 ICF 期限 |
| 研究结束后 30 天 | 同上 |

## 后果

- 对研究：ICF 写明。
- 对开发：删除是手动运行脚本，没有定时任务。
