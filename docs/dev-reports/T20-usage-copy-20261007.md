- 文档：`app_config/usage_copy`（Firestore）。规则沿用 `app_config/{doc}`：登录用户可读，客户端不能写，未登录不能读（`firestore.rules:133`；新测试 `test/rules/app_config_rules.test.js`）。
- 字段：第 1a 节的 11 个，必须是字符串。只认这 11 个，其它字段忽略。
- 默认：文档不存在 / 读取失败（3 秒超时）/ 字段为空 / 值里带【占位】→ 显示原文。
- 读取时机：App 启动时读一次（`lib/main.dart`，`lib/core/config/usage_copy_loader.dart`）。研究侧改了以后，老人重开 App 才看到。

## 要带回研究侧的发现

1. App 里现在**没有一处明说**"建议每天用、每周至少 5 次"。要不要新加一处（例如引导页或常见问题），放在哪里，研究侧定（backlog 69）。
2. 7 处现有文字的定稿措辞（第 1a 节；中文必填，英文 4 处可选）。定稿前一直显示原文（backlog 67）。
3. 常见问题里"就算一整個星期冇填"和"每周至少 5 次"的建议放在一起读，是否会让老人觉得矛盾，请一起看。
4. prompt 里两条"不催促"规则和"不强制"一致；要不要在 prompt 里加使用建议，改的话要新版本文件和 PI 审核（backlog 68）。
5. T21 拆分研究期配置时，`app_config/usage_copy` 建议列为两期共用配置（或者如果两期措辞不同，再分开），请研究侧确认。
