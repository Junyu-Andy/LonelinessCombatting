# NNNN：首页分两页（「睇今日」只放今天的事，「搵人傾」放三位伙伴），心情一行不弹窗，M7、M8 进小欣聊天由小欣先开口

- 日期：2026-10-20
- 状态：提议中（开发窗口草稿，等 Junyu 定编号和下面“要 Junyu 定”的几点）
- 影响范围：pilot、run-in（PB-）、rct（RCT-）× 两组（界面两组相同；只有 M7、M8 之后小欣的开场一句，规则组用模板、Hybrid 组用 LLM）
- 相关代码：分支 `claude/zealous-fermat-8rgqtg-batch3`（1020 第 3 批：D、E、G (2)，1020b 第二节 (1)(2)，做啲嘢工具图）

## 背景

10/19 产品窗口定（1020 第 D、E、G 节，1020b 第二、四节）：第一页太挤，老人找不到 check-in 和邀请卡；首页的心情弹窗和 Hybrid 组独有的小条、对话框是组间差异，也打扰老人。10/21 是冻结构建，所以新行为放在两个远程开关后面：`homeLayoutV2Enabled`（两页重排、问卷一行、工具图）和 `moodRowV2Enabled`（心情一行），默认关，只认字面 `true`，关着时一切照旧。

## 决定

1. **两页**：第一页就是底部第一个 tab「睇今日」，第二页是第二个 tab「搵人傾」。第一页的大按钮「去搵人傾」等于点第二个 tab（同一套使用记录）。
2. **第一页从上到下**：问候 → 心情一行 → 「今日要做嘅事」（check-in 一行；Brief PR 邀请卡；问卷一行；行动计划跟进）→「去搵人傾」→ 本周小结 → 危机支援卡。拿走：三位伙伴卡、继续聊天卡和第一周提示（搬到第二页）、三个工具捷径、每日心情弹窗、三天未做横幅（并入 check-in 一行）、旧的 check-in 状态小条（被 check-in 一行取代）。
3. **第二页**：「揀一個你想搵嘅人傾下。」→ Brief PR 邀请卡 → 继续聊天卡 → 第一周提示 → 三位伙伴。
4. **邀请卡两页都有**：两页放的是同一个 `BriefPrCardHost`，同一套调度规则；会话一结束（调度器写完）两页都刷新，App 回到前台或重新打开也刷新。在任一页答了或「今次唔評」，另一页也消失。
5. **check-in 一行**：每天都有。没做：空心圆，撳了进小欣页并开始当天 check-in；做完：打勾，不能撳。连续 3 天没做时，原来横幅的两句合成一句放在这一行下面（D3），不再另出横幅。
6. **问卷一行**（G (2)）：只在研究周排程开着时出现（`app_config/phase_b.weeklyScheduleV2Enabled`、Phase B 构建、已登记）；否则旧的问卷卡照旧。开放中、还没做完：W5「仲有 N 日」，撳了打开每周问卷；没开放或这一周做完了：W4 下次开放日。W7 之后不再出现。旧的待办横幅 `PendingPromptsBanner` 仍留在这一段（Phase A 项目等），但问卷一行出现时它不再显示每周问卷卡，免得两张。
7. **心情一行**（E）：不弹窗。状态：未答（M1、五个表情、M2）；撳 M2 后当天显示 M4，不再自动展开（记在手机本地，重开 App 也一样）；已答（M5、M6，刚揀完约 2 秒显示 M3）；M6 展开五个表情。每次揀都写一笔 `daily_mood`（字段不变：当天第一笔 `is_primary`，其余 `supplementary`，服务器时间，`source_surface: home_mood_row`）。撳 M2 写一个事件 `mood_checkin`（`skipped: true`）。五个表情和下面的字沿用首页原来的（好差、差、麻麻地、幾好、好好）。
8. **M7、M8**：M7 在当天第一次答完后出现，撳过、做完 check-in、或被 M8 取代后当天不再出现。M8 在再答且与上一笔不同时出现，撳过、App 退到后台或重开后消失。两者都要 `checkInChatV2Enabled` 也开着（小欣聊天窗口在那个开关后面），否则不出现。
9. **M7、M8 进小欣聊天，不是 check-in**：
   - 规则组：开场用 5.2 的 O1–O5（按刚揀的心情 5→O1 … 1→O5）或 C1（好咗）、C2（差咗），之后照第 2 批的回应池；O4、O5、C2 之后用 SN1–SN4，其余用 SY1–SY6。全程不调 LLM。
   - Hybrid 组：LLM 开场。提示词新版本 `siu_yan.v4.txt` = v3 + 一节「從首頁心情入嚟（開場）」：给出当前心情（M8 时加之前的心情和好咗／差咗），要求先承认心情、再用一条开放式问题问发生咩事，心情差时语气放慢、不分析、不给建议。App 传的只是心情和变化，不含老人写过的字。LLM 失败时用同一条 O／C 句。`moodRowV2Enabled` 开着时，这个窗口的所有 Hybrid 调用都用 v4（v4 只多这一节），关着时仍是 v3。
10. **旧路径不可达**（1020b 第二节）：`moodRowV2Enabled` 开着时，`homeMoodOpensCheckInEnabled` 怎么设都不生效（旧表情板根本不建，代码里另有一道判断）；`homeLayoutV2Enabled` 开着时，旧的 `briefPrHomeBannerEnabled` 横幅永远不显示，第一页只有一张邀请卡。
11. **做啲嘢工具图**：`homeLayoutV2Enabled` 开着时，四个工具左边换成 Junyu 的定稿图（`assets/tools/` 四张），各放在一块圆角方形色块里（60×60，四边各留 8%）；字不变，两组相同。关着时仍是原来的图标。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 第一页、第二页做成同一个 tab 里左右滑 | 老人已经习惯底部四个 tab；用现有 tab 改动最小，使用记录也不用改 |
| M8 跨天、跨重开都保留 | 1020b 5.1 写明「下次打开后不再显示」 |
| M8 消失后 M7 再出现 | M8「取代」M7；同一天再出 M7 容易重复邀请 |
| 心情一行改用 Q1 的五个说法（好開心…好唔開心） | 会改老人已经熟悉的表情文字；先不改，列给 Junyu 定 |
| Hybrid 开场只靠上下文块，不出新提示词 | 开场要“一定以一条问题收尾”，和 v3 的“唔使每 turn 都用問題收尾”不同，要写进提示词；按 CLAUDE.md 另开 v4 |
| 问卷一行在研究周排程关着时也按研究周算 | 排程关着时问卷其实按星期日窗口开，算出来的日子会错 |

## 后果

- 对研究：首页不再有每日心情弹窗，`daily_mood` 只来自心情一行（和小欣页）；之前弹窗的 `source_surface: daily_prompt` 不再出现，新行是 `home_mood_row`。Hybrid 组独有的小条和对话框没有了（组间差异减少）。规则组多了一个从心情进小欣聊天的入口，两组一样。新事件 `mood_row_chat_opened`（`prompt` M7／M8、`mood`、`previous_mood`、`direction`、`opener_id`）。提示词多一个版本 `siu_yan.v4`。登记表要加：首页结构、心情一行、M7／M8 开场（产品窗口）。
- 对开发：新文件见报告；改动集中在首页、搵人傾页、做啲嘢页、小欣聊天页（多一个 `moodEntry` 参数）。开开关前要先部署 Functions（有 `siu_yan.v4.txt`）。
- 对论文：方法部分写首页两页、心情记录方式（不弹窗、可多次、第一笔为主）、从心情进入聊天的开场两组来源不同；10/21 起生效。
