# 0032：规则组模板按定稿改成「陪伴者 × 五档心情」，回忆里的哀伤内容用 Z5，未确认的字不上线

- 日期：2026-10-10
- 状态：提议中（代码在开关后面，开关默认关；文中疑似错字等研究侧确认）
- 影响范围：phase_a、phase_b、pilot × 规则组（签到 B、回忆 B）；Hybrid 组不变
- 相关代码：`lib/features/rule_replies/`、`reminiscence_arm_b_page.dart`（T33，分支 `feat/final-copy`）
- 部分取代：0023 的「主题 × 3 档心情」分池和「命中 moderate 一律不给模板」两条

## 背景

0023 做的模板池是「陪伴者 × 主题 × 3 档心情」，文字全是占位。研究侧 10/10 定稿了 41 条（`docs/spec/copy/rule-templates.md`），结构不同：五档心情、阿珍不分周主题、多一条没选心情时用的 G-1；回忆里命中 `moderate_review`（哀伤、旧日艰难）时改为给 Z5 四条之一（10/10 第 3 条）。定稿里还有几处疑似错字，研究侧确认前不能给老人看。

## 决定

- **分池**：陪伴者 × 心情档。心情档 = 心情脸 1–5 各一档：5 好開心（X1 / Z1）、4 幾好（X2 / Z2）、3 一般般（X3 / Z3）、2 唔係幾好（X4 / Z4）、1 好唔開心（X5 / Z5）。阿珍、阿伯共用一套。不再按周主题分。
- **没选心情**（只有回忆会这样）：G-1。
- **回忆命中 `moderate_review`**：不看心情，从 Z5 选；照常写安全事件、走安全流程。签到命中 `moderate_review` 仍不给模板（定稿只给了回忆的哀伤规则）。
- **`moderate_interrupt`、`acute`**：两页都不给模板，只走安全流程。
- 选法（近 3 次不重复）、`rule_template_reply` 日志不变；`template_id` 改用定稿编号（X1-1 … G-1），`pool_version` = `2026-10-10-final`。
- **未确认的字**：每条带 `pending` 标记，照定稿「待确认的字」表设。只要还有一条带标记，开关打开也不生效。研究侧确认后，开发窗口先改 `docs/spec/copy/`，再改代码里的文字、去掉标记。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 只让没有疑似错字的 18 条先上线 | 有的心情档只剩 1–2 条，近 3 次不重复做不到；G-1 也带疑似错字，没选心情时没有回应 |
| 回忆的 `moderate_interrupt` 也给 Z5 | 定稿只说 `moderate_review`；interrupt 会弹支援面板，再加一条模板会重复 |
| 签到的 `moderate_review` 也给 X5 | 定稿没有这条规则，先保持不给，交研究侧定 |

## 后果

- 对研究：规则组回忆里讲到过世、旧日艰难的提交，从「没有回应」变成「有一条 Z5 回应」，开关打开后才生效。开关打开日期和影响的 cohort 写进 STUDY_CHANGELOG。
- 对开发：改模板池、服务和回忆页；`lib/core/safety/` 没改。
- 对论文：Methods 里规则组回应的描述按五档和 Z5 写。
