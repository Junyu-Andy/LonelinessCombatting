# 0009：只是约诊（睇醫生、覆診）的待跟进不算敏感

## 背景

「下禮拜四覆診」这类事正是待跟进想要的例子，但「醫」字会命中敏感词。

## 决定

只因为约诊字眼命中的待跟进不算敏感，陪伴者可以主动问「上次睇醫生點呀？」。癌、手术、病等诊断仍算敏感。

| 交给 PI 决定 | 负责人决定不需要 |
