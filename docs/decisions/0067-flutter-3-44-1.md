# 0067：Flutter 从 3.35.3 升到 3.44.1，只换工具版本；新版改掉的两处默认样子在 App 主题里锁回原样

- 日期：2026-10-20
- 状态：提议中（PR 草稿，等 Junyu 定是否进 10/21 冻结构建）
- 影响范围：所有 cohort（pilot / phase_b / rct）× 两组（相同）
- 相关代码：分支 `claude/zealous-fermat-8rgqtg-flutter344`（base 冻结分支 `claude/zealous-fermat-8rgqtg-freeze-1021`）

## 背景

10/01 起 Flutter 固定在 3.35.3：当时 CI 自动用了最新的 3.47，要求 Gradle 8.14，项目是 8.12，打包失败。交接 1020p 第一节要求升到 3.44.1，目标是「老人看到的、做的都不变，只换工具版本，两组相同」。

## 决定

1. CI、Build APK、Codemagic、`.metadata`、本机测试脚本都改为 Flutter **3.44.1**（Dart 3.12.1）。
2. `pubspec.lock` 只有 5 个跟着 Flutter 一起来的依赖变了（characters、matcher、material_color_utilities、meta、test_api）。**所有插件版本不变**（Firebase、录音、WebView 等），`pubspec.yaml` 的版本要求不变。
3. **Gradle 8.12、AGP 8.9.1、Kotlin 2.1.0 不升。** 它们在 3.44.1 的支持范围内（3.44.1 只在低于 Gradle 8.7、AGP 8.6、Kotlin 2.0 时拒绝打包；低于 Gradle 8.14、AGP 8.11.1、Kotlin 2.2.20 只提示）。升级它们会换掉 Android 打包工具链，Kotlin 2.2 还要改构建脚本，和「只换 Flutter」的目标不符。
4. 3.44.1 改了两处默认样子，在 `lib/app/app_theme.dart` 锁回 3.35.3 的样子（两组共用同一个主题）：
   - **Android 换页动画**：3.44.1 默认改成「预测返回」（滑动加淡入，450 毫秒）；锁回原来的「放大淡入」（`ZoomPageTransitionsBuilder`，代码和 3.35.3 相同）。iPhone 不受影响。
   - **四个由主色推出来的字色**（`onPrimaryContainer`、`onSecondaryContainer`、`onTertiaryContainer`、`onErrorContainer`）：3.44.1 的颜色库推出来的颜色变浅了。这几个颜色用在浅色按钮、页顶提示、Brief PR 邀请卡、漏签到提示、登录错误提示等地方的字上。锁回 3.35.3 推出来的值。
   - 核对：把两种主题（普通、高对比）的所有颜色、字体、间距、换页动画逐项列出来比，锁回后 3.44.1 和 3.35.3 完全一样。
5. **iPhone 包的插件仍用 CocoaPods 组装。** 3.44.1 默认改用 Swift Package Manager（3.35.3 是 CocoaPods），Firebase、录音、WebView 等插件都会换一种方式装进 iPhone 包。`pubspec.yaml` 加 `flutter: config: enable-swift-package-manager: false`，组装方式和以前一样。冻结后再评估。（3.44.1 另一个 iOS 默认「迁移到 UIScene 启动方式」对本项目不起作用：`Info.plist` 已经是 UIScene。）

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 不升，留在 3.35.3 | 可以。冻结前不升也不影响研究；只是以后升级的差距更大。由 Junyu 定 |
| 一起升 Gradle、AGP、Kotlin 到 3.44.1 不提示的版本 | 不是必须的；会改 Android 打包工具链和构建脚本，风险比收益大。下次升 Flutter 时单独做 |
| 一起升插件（`record` 7.x、`webview_flutter` 4.14 等） | 插件代码变了，老人用到的录音、小讀本可能变；冻结前不升 |
| iPhone 跟着 3.44.1 改用 Swift Package Manager | 换了插件和 Firebase SDK 的组装方式，冻结前不值得冒险 |
| 接受新的换页动画和颜色 | 老人看得到，违反「只换工具」 |

## 后果

- 对研究：两组完全相同，操纵定义、测量、对等性都不变。不用改注册、protocol、ICF、HREC。
- 仍有一处没能锁回：**Android 上把列表拉过尽头时的「拉伸」回弹**，3.44.1 改成更接近手机原生的画法（只在拉过头那一下出现，内容和操作不变）。锁回要复制框架代码，不值得。真机走查时看一眼。
- 引擎（Impeller）也更新了。静态画面已用全部 12 个截图测试文件（100 个用例，含两组、普通和高对比、大字、iPad）逐个像素比过（3.35.3 画一次，3.44.1 按同一批图比较，全部相同），真机上的字体、输入法、录音要靠手机走查确认（`docs/release/flutter-3441-phone-check.md`）。
- **iOS 的一个发现**：`ios/Runner/AppDelegate.swift` 用了 `FlutterImplicitEngineDelegate`，3.35.3 里没有这个接口（3.44.1 有）。所以按 3.35.3 打 iPhone 包，很可能编译不过；升到 3.44.1 以后应该能编。这里没有 Mac，没法验证，要在 Mac 或 Codemagic 上确认。以前给 iPhone 打的包如果是用更新的 Flutter（例如 3.47）打的，那么 iPhone 的对照基准就不是 3.35.3。
- Android 签名不变：签名设定在 `android/app/build.gradle.kts` 和 Build APK 工作流里，这次都没动；新包和旧包是同一把钥匙，可以直接覆盖安装。
- 对开发：`flutter analyze` 3.35.3 和 3.44.1 都是 92 条，同一批（位置、规则都一样），0 个 error。测试只改了一处：`test/reader_test.dart` 的测试外壳改用 App 自己的主题（原来用 Flutter 默认主题，3.44.1 下换页变慢，等不到页面关完）。
- 下次升 Flutter：先单独升 Gradle 8.14+、AGP 8.11.1+、Kotlin 2.2.20+（`kotlinOptions` 改 `compilerOptions`）。
- 对论文：不用写。
