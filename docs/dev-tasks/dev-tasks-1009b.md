## T25 会话定义与 Brief PR（分支 `feat/session-briefpr`，SPEC:C16、C14；T24 合并后开）

依据登记表 v3 的 C16、C14；10/8 交接 R1–R5；10/9 第 1、3 条。

1. **会话**：按陪伴者分开。结束：收尾按钮（左上角，文字【占位】，建议"← 倾到呢度先"；首次使用一句说明【占位】）、返回键或侧边返回手势（按实际导航测试）、切换陪伴者、连续 30 分钟无新消息。切 App、接电话、锁屏只算暂停。App 关闭或崩溃按已存消息和时间恢复判断，不靠退出瞬间的弹窗。
2. **有效会话**："完成一个互动单元"。
   - 自由聊天（通通、Hybrid 反思对话等）：老人至少发 3 条消息并收到相应回复。
   - Hybrid 小欣签到：心情已记录，且老人至少发 1 条消息并收到回复（`docs/dev-reports/product-reply-20261009.md` 第四节提议，待主窗口确认，做成配置项）。
   - Hybrid 阿珍回忆：按"儲存"保存了本周小结（同上，待确认）。
   - 规则组签到 B、回忆 B：必填项填完、提交、看到回应页（模板或固定句）。一次提交算一次会话（决策 0015，保留）。
3. **会话日志字段**：参与者、会话编号、陪伴者编号、会话类型（自由聊天 / 签到 / 回忆）、开始和结束时间、结束方式（按钮 / 返回 / 切换 / 超时 / 恢复判断 / 危机）、老人消息数、回复数、是否有效、当天该陪伴者是否已邀请。字段名用英文，写定后在报告里列表。
4. **每人每周有效会话数**能导出（只进非盲导出和锁库后分析导出）。
5. **Brief PR 邀请**（R2）：
   - 只在有效会话结束后邀请，不在聊天中邀请，不设主动评价入口。
   - 每位陪伴者每天最多 1 次（配置项，以后可能改为三位合计每天 2 次）。当天已邀请过的，后面的有效会话不生成评分记录，只在会话日志标出。
   - 收尾、返回、切换结束的：在陪伴者列表页显示评价卡，不遮挡聊天、不阻止返回。
   - 超时、App 关闭结束的：下次打开补问一次，卡上写明是哪次聊天（例如"今天 15:20 与某位陪伴者的聊天"，【占位】）。距该次会话最后一条完整回复超过 2 小时记为过期。
   - 评价卡有完整文字的"这次不评"按钮，点击区域至少 48 × 48，放大字体后能用。
   - 点"开始评价"才打开问卷：一次一题，显示 1/4；选项用完整文字；"下一题""提交"分开；有"返回"和"放弃评价"。题干"今次倾偈"，4 题和量尺不变。
   - 危机处置中不邀请。评分不作为聊天消息、不进记忆，陪伴者不回应评分。
   - 网络错误时保存答案并重试；后台、断网、崩溃后不能重复提交。
6. **Brief PR 状态**（R3）：最终状态五选一（completed、partially_completed、skipped、expired、due_not_invited）＋ `everShown` 布尔。"展示未答"只是过程状态：2 小时结束仍未答记为 expired、`everShown = true`。due_not_invited 只用于危机处置、系统故障等，记原因字段。字段名可按代码风格调整，写定后在报告列出。
7. **Brief PR 记录字段**（R4）：参与者、会话编号、陪伴者编号、会话结束时间、邀请时间、评分时间、邀请方式（列表页 / 补问）、最终状态、`everShown`、4 题原始分（不敏感题不反转）。进非盲导出和锁库后分析导出；**不进**盲法导出。
8. **全体合并的 Brief PR 完成率**（不分人、不分组），给盲法评估者看负担用。
9. **记忆写入时点**（R5）：只在 Hybrid 组；会话结束时写入，不等 Brief PR；Brief PR 内容不进记忆。
10. `llm_calls` 每条加会话编号（产出窗口第 1 条）。
11. 30 分钟超时等新规则只对 Phase B 生效，用 T21 的按研究期配置。
12. 旧的弹窗式 Brief PR 和"首次没有跳过"（anchor）的规则怎么处理，写进决策记录。
13. 测试：会话结束各路径（含手势返回、切 App 30 分钟内回来、崩溃恢复）、有效与否、上限、补问和过期边界（1:59 / 2:01）、重复提交、两组一致。

输出：PR 草稿 + `docs/dev-reports/T25-session-briefpr-YYYYMMDD.md`（含字段表、截图）。
