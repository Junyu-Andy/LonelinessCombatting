# 0063：每一轮聊天的原话和回复另存一份研究用原文，老人和 App 都读不到

- 日期：2026-10-20
- 状态：提议中（Junyu 10/20 晚 1020l 要求先做；开关什么时候开、知情同意怎么写，等 Junyu 定）
- 影响范围：phase_b、pilot（含 RCT-）× 两组；测试员也写；开关打开后的聊天
- 相关代码：分支 `claude/zealous-fermat-8rgqtg-transcript`；`lib/core/session/chat_session_recorder.dart`、各聊天页、`firestore.rules`、`lib/core/feature_flags/remote_feature_flags.dart`、`functions/blinding.js`、`tool/check_blinded_export.js`

## 背景

1020j 第一节查出：小欣、通通的聊天和 check-in 聊天，两组都没有逐条保存陪伴者的回复；Hybrid 组 AI 的回复在哪里都没存；老人原话只在 Hybrid 组、开了「保留」时短暂存在，会话结束就折叠成摘要。操纵检验的编码导出（每人抽 3 次会话的原文）因此取不到。规则组的回复在手机上生成、不经过服务器，所以只改服务器做不到，要改 App。

## 决定

1. 新开关 `app_config/feature_flags.researchTranscriptEnabled`（**默认关**，只认布尔 `true`）。关着时什么都不写。
2. 开着时，所有聊天页每一轮（两组：小欣聊天和 check-in、通通、阿珍／阿伯回忆 v1 和 v2、想法练习对话、规则组提交页）在原有的 `turns` 记录之外，再写一行 `users/{uid}/chat_transcripts/{turnId}`（和 `turns` 同一个编号）：会话号、陪伴者、模块、老人原话（语音就是转出来的文字；只按按钮的那轮为空）、屏幕上显示的回复、回复来源（模型、规则模板、固定句、安全中断）、两个时间、服务器收到时间。不写组别。
3. 写的是 App，在后台发，失败也不影响聊天；离线时排队，联网后补发。
4. 规则只许本人在登记后（或测试员）**新建**，字段和长度都限死（原话 ≤ 5000 字，回复 ≤ 10000 字），开关不开就拒绝。**任何客户端都不能读、改、删**——老人自己、其他账号、研究员角色都不行。只有服务器管理权限（Admin SDK）能读，删除参与者的脚本一并删除。
5. 这个集合不进任何盲法导出（`HELD_BACK`）。
6. 和「保留對話紀錄」（陪伴者记忆，现在隐藏）无关：那是给陪伴者记住用的，这个是研究存档。是否需要在知情同意书里另写一句，由 Junyu 定，定了再开开关。
7. 不调用任何模型；规则组照旧零 LLM。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 只改服务器（模型入口顺手存） | 规则组的回复不经过服务器；Hybrid 的急性中断、模型失败也不经过 |
| App 调一个新的服务器入口来存 | 离线时会丢；Firestore 自带离线排队更稳，而且不用新部署 Function |
| 直接在 `turns` 行里加原话 | `turns` 本人可读，而且已经在好几个导出和看板里，容易漏到盲法那边 |
| 跟「保留」开关走 | 这个开关隐藏、默认关，跟着走就等于什么都不存 |

## 后果

- 对研究：开关开了以后才有原文，之前的聊天补不回来（1020j 已报）。操纵检验的编码导出、看板「查看對話」从此有数据源，但读取工具还没做（见 backlog）。数据最敏感，只能由非盲角色经管理权限读取。
- 对开发：App 改 16 处记录调用（加原话一项）、记录器一处、开关一个；规则一段；删除测试、规则测试、Dart 测试。要部署 `firestore.rules`。
- 对论文：方法部分写明「研究期间保存每轮对话原文用于操纵检验」，并和伦理批文核对。
