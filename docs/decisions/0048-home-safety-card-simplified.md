# 0048：首页安全卡改成两部分：先「情緒通 18111」，再「如果唔安全，睇更多支援熱線」；卡上不再单独放「撥 999」

- 日期：2026-10-19
- 状态：提议中（Junyu 10/19 提出，待 PI 审核：这是危机界面）
- 影响范围：pilot / phase_b × 两组（两组完全相同）
- 相关代码：分支 `claude/zealous-fermat-8rgqtg`；`lib/features/crisis/presentation/widgets/safety_footer_card.dart`

## 背景

「睇今日」底部的安全卡（2026-07 版）有三层：情緒通 18111、红色「如果你或身邊嘅人有即時生命危險　撥 999」、「更多支援熱線」。Junyu 10/19 核对时觉得排版难看，999 那一行放在这里很突兀，「有真人聽你講」也多余；同时确认这张卡和「自己 → 危機支援」本质是同一个功能（卡是快捷方式，「更多支援熱線」打开的就是危機支援页）。

## 决定

1. 第一部分：「想搵人傾吓？」居中；「情緒通」和 18111 分两行；耳机和电话图标放在同一个圆角按钮里；下面一行「24×7 政府熱線」；去掉「有真人聽你講」。整块一按就拨 18111（号码不变）。
2. 第二部分：「如果唔安全，睇更多支援熱線」，打开危機支援页。那一页的热线列表照旧，急症室 / 999 仍然突出显示。
3. 卡上不再有单独的红色「撥 999」一行。
4. 不改：任何热线号码；危机检测；命中 acute 时自动打开危機支援页的流程；危機支援页本身。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 保留三层，只改文字 | Junyu 觉得 999 放在首页卡上不合适、界面太挤 |
| 999 和 18111 并排两个按钮 | 首页本意是先降低开口的门槛（2026-07 设计说明）；危险情况由危機支援页和自动弹出处理 |

## 后果

- 对研究：危机界面改动，两组相同，不影响对等性。PI 审核后在 STUDY_CHANGELOG 补审核日期。ICF / 培训材料如果写了「首页有 999 按钮」要改成「首页 → 如果唔安全，睇更多支援熱線」。
- 对开发：`logEmergencyOpened` 不再有 `…-999` 这个来源（首页卡）；危機支援页内的 999 记录不变。
- 对论文：无。
