# T9 关闭"搜一搜"和语音输入（SPEC:C18）

日期：2026-10-07。分支 `chore/phaseB-flags`。决策记录 0019。

## 结论

- 加了一份服务器和 App 共用的配置 `app_config/feature_flags`，三个开关，**全部默认关**。没有这份文档就等于全关，上线前不用建。
- 关的时候两层都关：App 不显示入口、不发请求；服务器 `webSearch`、`transcribeAudio` 直接拒绝。
- 现在线上：**搜一搜在 App 里本来就触发不了**（2026-07-20 起写死关闭），但服务器接口还开着；**语音两组都开着**。合并部署后，两项都关。
- 通通遇到要上网查的问题，有一句固定回应，现在是占位文字，开关默认关，草稿见第 4 节。

## 1. 开关

配置位置：Firestore `app_config/feature_flags`（客户端只读，`firestore.rules` 现有 `app_config` 规则，未改）。字段必须是布尔值 `true` 才算开。

| 开关名 | 默认 | 作用 | 代码 |
|---|---|---|---|
| `webSearchEnabled` | 关 | 通通"幫我查"按钮和 `webSearch` 函数 | App：`tung_tung_page.dart:108`、`search_repository.dart:54`；服务器：`functions/index.js:608` |
| `voiceInputEnabled` | 关 | 所有页面的麦克风按钮和 `transcribeAudio` 函数。**重要功能：HREC 批准 STT 后开启** | App：`voice_input_button.dart:122、148、439`；服务器：`functions/index.js:701` |
| `searchOffReplyEnabled` | 关 | 搜一搜关闭时，通通对"要上网查"的问题回固定的一句 | `tung_tung_page.dart:115、320、680`；`tung_tung_search_intent.dart` |

读取：App 启动时读一次（`lib/main.dart`，`RemoteFeatureFlags.load`），读不到就全关；服务器每次调用都读（`functions/feature_flags.js`），读不到也算关。

## 2. 搜一搜：现状和改后

**改之前（main 9642ac5）**

| | Hybrid 组 | 规则组 |
|---|---|---|
| App 里有没有入口 | 没有。`_searchEnabled = false` 是常量，按钮不显示，`_searchArmed` 永远是 false，所以 `search()` 从不调用（2026-07-20 提交 8ef864a 起） | 没有。规则组走 `_sendRuleBased`，不调用搜索 |
| 服务器 `webSearch` | 能用：只查登录和分组。登录的 Hybrid 组账号绕过 App 直接调用，会把查询词发给 Brave | 拒绝（`assertLlmAllowed`） |
| 分组为空的账号 | 服务器不拦（T2 报告） | — |

所以**线上 App 里老人触发不了搜索**，T2 说的"搜索词在安全检测前发给 Brave"（当时 `tung_tung_page.dart:300–302`）是打开搜索后的路径，目前走不到。

**改之后**：开关关时，App 端按钮不显示、`search()` 直接返回不发请求；服务器在发给 Brave 之前就拒绝，三类账号（Hybrid、规则、分组为空）一样。开关开时，规则组仍没有按钮，服务器仍拒绝规则组。

## 4. 固定回应

**什么时候出现**（两组条件相同，`tung_tung_page.dart:115`）：

1. `searchOffReplyEnabled` 开，且 `webSearchEnabled` 关；
2. 不在文章问答模式；
3. 老人的话命中关键词表（`tung_tung_search_intent.dart`：幫我查、查一查、上網查、搜尋、天氣、天文台、新聞、幾點開、幾錢、價錢、地址等；故意不放"查下""上網""邊度有""點去"，因为"檢查下""唔識上網""邊度有人關心我""點去面對"也会命中）；
4. 安全词库对这句**没有任何命中**。只要命中（moderate 或 acute），照原来的安全流程走，不出这句。

| | Hybrid 组 | 规则组 |
|---|---|---|
| 出现时 | 不调用 AI，直接显示这句；`turns` 记 `llmStatus: fixed_reply`；不写记忆缓冲区 | 用这句代替话题模板；`turns` 照旧记 `rule_based` |
| 事件 | `tung_tung_search_off_reply {arm: A, version}` | `tung_tung_search_off_reply {arm: B, version}`，加上原有的 `tung_tung_rule_reply`（`template_id: search_off_fixed`） |
| 开关关时（默认） | 照旧交给 AI。按 v2 prompt，AI 会老实说不确定，不再邀请上网查（第 5 节） | 照旧按话题选模板 |

代码里的占位：`【占位：搜一搜關閉時嘅固定回應，待研究團隊定稿】`。

**文字草稿（待研究侧定稿）**：

- 草稿 1：「呢樣嘢要上網查先知，我而家查唔到住。你可以問下屋企人或者社工，佢哋可能幫到你。我哋不如傾下第樣嘢？」
- 草稿 2：「哎呀，呢啲最新嘅資料我冇辦法即刻查到。如果好緊要，可以問下身邊嘅人。你今日有冇咩想同我分享？」

英文版（App 英文界面用）："I can't look that up right now. Family or a social worker may be able to help. Shall we chat about something else?"

## 5. 通通 prompt v2（需 PI 审核）

负责人 2026-10-07 决定：搜一搜关了，通通不再邀请老人"幫你查"。

- 新文件 `functions/prompts/tung_tung.v2.txt`；`tung_tung_v1.txt` 不动。
- App 仍发 `tung_tung_v1`（已装的 App 也一样）。服务器在 `functions/index.js` 的 `PROMPT_FILES` 里把它换成 `tung_tung.v2`。转介判断（`referralJudgement`）读通通 prompt 时也走这里。
- `promptVersion` 从 `tung_tung_v1@2026-06` 变为 `tung_tung_v2@2026-10`，写进每条 `turns`。
- 版本锁：`build_info.g.dart` 和 `test/phase_a_version_pin_test.dart` 加上 v2 文件。

**新旧差异**（只改首行版本号和模式 B 第 4、5 点，其余一字不动）：

| | v1 | v2 |
|---|---|---|
| 首行 | `· v1 (rev 2026-06)` | `· v2 (rev 2026-10)` |
| 第 4 点 | 有 `[SEARCH_RESULTS]` 就只引用搜索资料作具体事实。冇 result 就老实话「我未確定，要唔要一齊查下？」唔好作 specific 數字。一般常識照講 | `[SEARCH_RESULTS]` 规则**保留**。冇 `[SEARCH_RESULTS]` block，或者入面冇可用結果：老實講你唔確定，唔好作 specific 數字（日期／價錢／地址），可以建議佢問下屋企人或者社工。一般常識照講 |

App 里还有一段备用 prompt（只在读不到 persona 时用，`tung_tung_page.dart` 的 `_fallbackPersonaPrompt`），也写着"要唔要一齊查下"。这次没改（不在 prompt 文件里，且 T7 在改这个文件），列为发现。

## 8. 要带回研究侧的发现

1. **固定回应的文字和关键词表**要研究侧定稿（第 4 节）。定稿前 `searchOffReplyEnabled` 保持关。
2. **通通 prompt v2 需要 PI 审核**（第 5 节）。v1 邀请"要唔要我幫你查下？"，搜索关着，老人答"要"之后什么也不会发生（2026-07 起一直如此）。v2 去掉了邀请。App 备用 prompt 里同样的话还在。
3. **键盘自带的语音输入 App 关不掉**。老人用 Gboard 麦克风或 iPhone 听写说话，声音交给键盘厂商。ICF 是否要提，由研究侧定。
4. **重新打开语音前**要先定：允许系统云端识别（现在 `_onDeviceOnly = false`，`voice_input_button.dart`），还是只在本机识别。代码里的类注释写"HREC 要求音频不离开设备"，与现在的设置相反（T1、T2 已报）。
5. **开关只在 App 启动时读**。新装 App 第一次打开时还没登录，读不到，算关；以后打开语音，老人要重开 App 才看到。关闭方向不受影响。
6. 如果以后重新打开搜一搜，T2 指出的两点还在：搜索词在安全检测之前发出，且不去个人信息（`tung_tung_page.dart` 搜索段）。T7 正在统一检测入口，打开前要先改。
