# 0013：被安全标记的对话不进入记忆

> 补记（2026-10-04）：这个决定当时在对话里做出，代码已合并。按模板补写，内容以当时的讨论为准。

- 日期：2026-09-29
- 状态：已采纳
- 影响范围：所有 cohort × Hybrid 组
- 相关代码：PR #23

## 背景

原来四个 A 组聊天页会把触发 moderate/acute 的那一轮写进记忆缓冲区，之后被整理进摘要、发给 DeepSeek、下次对话再提起。

## 决定

触发 moderate 或 acute 的轮次（包括陪伴者对它的回复）不写入记忆缓冲区。记忆 v1 在服务器上再查一次自杀、自残等词，命中的内容任何一层都不写。

## 后果

- 对研究：记忆里不会出现危机相关内容；陪伴者不会在之后的对话里主动提起。
- 对开发：回忆 A 组的研究记录仍保存 acute 那一轮的原文，这是研究数据的决定，没有改。
