# 1020c「讀少少」小讀本：做了什么、怎么测、要 Junyu 定的事（2026-10-20）

**结论**

- **做好了，全部在开关后面。** 开关 `app_config/feature_flags.htmlReadersEnabled`，只认布尔 `true`，**默认关**。关着时「讀少少」和现在一模一样。
- **开着、并且有单元时**：「讀少少」页顶多一节「小讀本」。点进去，App 用手机自带的网页组件（WebView）显示 Junyu 写的 HTML。
- **两组看到的一样**：内容、列表、阅读页、三个行动按钮都相同。唯一差别沿用登记表 C08：Hybrid 组页底多一个「問下通通」。规则组没有这个按钮，也没有任何调用模型的路径（有测试）。
- **不连网**：单元随 App 打包。App 载入时给页面加一条安全规则，外面的图片、字体、脚本一律不准载入；链接只放行三个行动按钮，撳别的链接什么都不发生，不开浏览器。CI 里另有检查脚本把关。
- **记录**：四种使用事件（打开、读到哪一节、撳了哪个按钮、停留秒数），只有编号和秒数，**不含任何文字**。
- **现在老人看不到**：仓库里的 `assets/readers/manifest.json` 是空表 `[]`。就算开关开了，没有单元也不显示「小讀本」一节。Junyu 10/20 22:00 前定稿的单元放进来才会出现。
- **合并前必须做的**：GitHub Actions 打一次 APK，Codemagic 打一次 iOS 包，iPhone 和安卓真机各按第 10 节测一遍。这台开发机连不上 Google 的下载站，也没有 Mac，**没能实际编出 APK 和 iOS 包**。
- **要 Junyu 定的事**见第 12 节（7 项）。

依据：`docs/dev-tasks/dev-tasks-1020c.md`；评估报告 `docs/dev-reports/webview-eval-20261020.md`；决策草稿 `docs/decisions/0056-html-readers-webview.md`。分支 `claude/zealous-fermat-8rgqtg-readers`（PR #130 草稿）。

## 3. 阅读页怎么显示 HTML（1020c 第一节 (3)）

- **从 App 内读文件**：`assets/readers/<id>.html` 读成文字，加工后用 `loadHtmlString` 显示，不给网址。JavaScript 开着。所以页面里的 CSS、JS、图片都要写在文件里（图片用 `data:` 或内嵌 SVG）。
- **App 加的四样东西**（`lib/features/education/data/reader_html.dart`）：
  1. `<head>` 最前面：安全规则（CSP）。只准用文件自己写的样式和脚本、`data:` 图片字体；连网（fetch、XHR、WebSocket）、框架、表单一律不准。
  2. `</head>` 前：禁止缩放的 viewport（另外 App 也调 `enableZoom(false)`）。
  3. `</head>` 前：`:root{--fs:X}`。X 是 App 现在画字用的倍数（`MediaQuery.textScalerOf(context).scale(1)`），五档 1.06–1.30 和「只认 App 字號」开关都已算在内。另外关掉 iPhone 横屏自动放大字、长按选字和链接菜单。
  4. `</body>` 前：一小段脚本，某一节（`data-section`）的上缘到了屏幕约三分之二处（或已滚到底），就回报一次这一节的编号。
- **安卓**：`setTextZoom(100)`，手机系统字号不再叠加；关文件和内容读取。**iPhone**：关长按链接预览。
- **链接**：只放行页面第一次载入和三个 `peizhu://cta/…`；网址、`tel:`、`mailto:`、其他 `peizhu://`、页内 `#` 跳转都拦下，不开浏览器。
- **返回**：顶上返回箭头、安卓返回键、iPhone 左缘右滑，都回到「讀少少」。网页从不跳页，所以没有"网页里的上一页"。
- **WebView 包在一个接口后面**（`lib/features/education/presentation/reader/reader_surface.dart`），和语音输入的 `VoiceRecorder` 一样：App 用 WebView，测试用替身。

## 6. 使用事件（第一节 (5)）

写进现有的 `users/{uid}/usage_events`，经现有的 `UsageEventRecorder`：

| type | 多出的字段 | 什么时候 |
|---|---|---|
| `reader_open` | `unitId` | 打开阅读页 |
| `reader_section` | `unitId`、`sectionId` | 某一节第一次读到（每次打开每节最多一次） |
| `reader_cta` | `unitId`、`cta`（`small_action`／`plan`／`thought`） | 撳行动按钮 |
| `reader_close` | `unitId`、`seconds` | 离开阅读页 |

- **不含文字**：编号只能是小写字母、数字、`_`、`-`（最长 48）。App 不合格就不写，服务器规则也拒收；`sectionId` 还必须真的出现在这个单元的文件里。
- **停留秒数** = 阅读页真正在屏幕上的时间：去行动页、去问答、App 退到后台时都暂停。手机放着不动最多记 86400 秒。
- **Firestore 规则**（`firestore.rules`）：每种只准带自己那几个字段；前台／后台事件不准带这些字段。规则测试 8 条新加，全过。
- **服务器**：`functions/usage_events.js` 给这四种也盖研究编号、香港日期、研究日。`functions/ops_dashboard.js` 算"前台分钟"只看前台／后台两种（不然读本事件会把一段前台时间切短）；找"最后一次打开"多看几行（10 → 60）。
- **导出**：`process_export.js` 和 `tool/analysis_export.js` 本来就不读 `usage_events`（使用量来自会话），这次**不用改**；盲法导出本来就排除整个 `usage_events`。要分析读本使用，要另外加一个导出（第 12 节第 5 项）。

## 7. 检查脚本 `tool/check_reader_html.js`（第三节）

`node tool/check_reader_html.js` 检查 `assets/readers/` 每个文件，不过就列出原因、退出码 1。CI（`.github/workflows/ci.yml` 的 Flutter 那一组）每次都跑，还跑它自己的测试（`test/reader_html_check/`，好、坏、空三组样例）。空的 `manifest.json` 能过。

| 1020c | 查什么 |
|---|---|
| (1) | `src`、`href` 等以 `http://`、`https://`、`//` 开头；`@import`、`url(` 指向外部。另：引用别的文件（如 `<img src="a.png">`）也不行，App 里载不到；链接只能是三个 `peizhu://cta/…` 或页内 `#` |
| (2) | `fetch(`、`XMLHttpRequest`、`WebSocket`、`localStorage`、`<form`、`<input`、`<textarea`、`tel:`（另加 `sessionStorage`、`indexedDB`、`sendBeacon`、`EventSource`、`<iframe`、`<object`、`<embed`、`<base`） |
| (3) | 连续 8 位数字或「xxxx xxxx」（也认连字号、全角数字）。`.html`、`.txt`、标题都查。`data:` 图片、SVG 坐标、颜色码不算 |
| (4) | 正文、`alt`、`title` 里有「AI」「模型」「機械人」「版本」「組」（也查简体「机械人」「组」）。注释、`<script>`、`<style>` 里的不算。`.txt` 和标题也查 |
| (5) | 有 `data-section`（编号格式同上、不重复）；有同名 `.txt`；在 `manifest.json` 里；`manifest.json` 里每个编号都有 `.html` 和 `.txt`；格式 `{"id","titleZh","minutes","order"}` |
| (6) | 每个文件小于 1 MB |
| 另加 | 页面要用到 `var(--fs)`，否则 App 的字號对这篇不起作用；目录里只放 `.html`、`.txt`、`manifest.json` |

## 14. 已知限制

- 没有实际编出 APK 和 iOS 包（见结论）。
- 截图里网页是替身；WebView 的实际表现只能在手机上看。
- App 被系统杀掉时还开着的读本，不会有 `reader_close`。
- 安卓很旧、「Android System WebView」很久没更新的手机，网页可能显示不全；写稿时 JS 用保守写法（不用 `?.`、`??`）。
- 高對比模式不会自动套到网页里。
- 包会大约 1 MB（评估报告第 3 节）；安卓 arm64 Dart 部分实测 +0.31 MB（含读本页本身）。
