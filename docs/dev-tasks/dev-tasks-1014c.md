### T39 运营看板（扩 T30 / C19，只给非盲角色）
目的：PI 在数据收集期间看老人用 App 的情况。示意图在产品窗口的“运营看板示意”画板（两页：总览、每人）。试跑 10/15 开始就要用，每人页先做。

边界（10/9 第 17 条；T30 第 4 节）：
1. 过程数据可按人、按组看：会话、Brief PR、Weekly PR、使用量、记忆、语音、安全事件。
2. 结局问卷（DJG-ES、UCLA-3、PHQ-9、GAD-7、PGIC、社会接触探针、继续使用意向、AIMHS）只显示“已填 / 未填 / 窗口中 / 未到”和全体合并完成率，不显示分数，不按组；全体少于 5 人时完成率显示“人数不足”。

4. 评估员角色（`blinded`）没有入口，直接访问被拒。
5. 打开看板写审计日志（谁、何时）。

第 1 页 总览：已登记人数按研究期和按组；今天有过有效会话的人数、过去 7 天有效会话总数；未确认处理的告警数按级别；本周每周问卷完成率（合并，少于 5 人不显示）；未来 7 天到期事项（每周问卷推送日、W4 可做日、W4 目标日、W8 推送日，不含组）；“需要我做的事”（连续 3 天和 7 天没用、每周问卷过窗未填、告警待确认）；过去 14 天每日有效会话柱状图（合并）。

第 2 页 每人（表格，一行一人，可按研究编号、研究期、组筛选，可只看 3 天没用的）：研究编号、研究期、组、研究第几天、最后一次使用；有效会话总数和按陪伴者（小欣 / 阿珍或阿伯 / 通通）、按类型（自由聊天 / 签到 / 回忆）；Brief PR 邀请 / 完成 / 部分完成 / 跳过 / 过期；每周问卷 W1–W8 每周一格；每日心情填写天数；记忆条数共享层 / 私有层（规则组显示“不适用”）；语音使用次数 / 失败次数；安全事件数按级别和是否待确认；W8 和 debrief 状态。点研究编号展开该人最近的会话列表（时间、陪伴者、类型、老人消息数、时长、结束方式、是否有效、Brief PR 状态），不含对话原文。
