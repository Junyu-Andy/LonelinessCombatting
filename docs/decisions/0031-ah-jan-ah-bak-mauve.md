# 0031：阿珍、阿伯改成紫色系（阿珍藕紫、阿伯灰紫），通通保留绿色

- 日期：2026-10-10
- 状态：已采纳（负责人 2026-10-10 在预览里选定方案 C）。第一位参与者入组前请 PI 过目
- 影响范围：所有 cohort × 两组（相同）
- 相关代码：分支 `claude/eloquent-ride-55w633`；`assets/agents/ah_jan_*.png`、`assets/agents/ah_bak_*.png`、`lib/core/agents/agent_registry.dart`、`lib/features/agent_profile/data/agent_profile_content.dart`、`lib/features/today/presentation/widgets/agent_tile_row.dart`、`continue_chat_card.dart`

## 背景

阿珍的图是薄荷绿身体，和通通几乎同色，选了阿珍的老人首页会看到两个绿色机械人。阿珍、阿伯在代码里的主题色是淡紫（`#AFA9EC`），图里却是绿色和灰蓝色，对不上。负责人看图也觉得现在的配色不舒服。

## 决定

1. 通通不变（绿色）。小欣不变。
2. 阿珍：身体从薄荷绿改成藕紫，胸口和扇子从淡紫改成淡粉。阿伯：身体从灰蓝改成灰紫。
3. **只改色相，不改深浅**：每个像素原来多浅、多饱和都保持原样，图案、表情、线条都不动。负责人看了预览，明确不要把颜色调浅。用的脚本是 `tool/assets/recolor_hue.py`。
4. 代码里阿珍/阿伯的颜色跟着改成同一个紫色系：

| 用在哪里 | 原来 | 现在 |
|---|---|---|
| 主题色（找不到图时的圆圈、介绍页） | `#AFA9EC` | `#C4A3CE` |
| 首页卡片头像底色 | `#EEEDFE` | `#F6EEF8` |
| 首页卡片头像圈、「傾偈」按钮底色 | `#B3ACDE` | `#C9A9D4` |
| 「傾偈」按钮文字 | `#2A2454` | `#3B2347`（和底色对比 6.7:1，原来 6.7:1） |
| 首页「繼續傾偈」建议条上的「珍」字 | `#3C3489` | `#6A3A78`（和底色对比 7.4:1） |

5. 介绍页图片的读屏说明从「淡紫色」改为阿珍「藕紫色」、阿伯「灰紫色」。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 阿珍淡紫、阿伯灰紫（颜色调浅） | 预览里胸口和扇子太浅，像半透明，负责人觉得奇怪 |
| 奶茶色 | 负责人选了紫色系 |
| 雾蓝 | 偏冷 |
| 蜂蜜黄 | 通通身上也有黄色，小欣是暖橙，三个都挤在暖色区 |
| 改通通的颜色 | 负责人定通通就是绿色 |
| 重画（连表情一起改） | 这里做不到，要另找画师或出图工具；先只改颜色 |

## 后果

- 对研究：Phase A 在测「分不分得清三位陪伴者」（ADA）。这次改色是为了让陪伴者更好分，要在第一位参与者入组前上线，两组看到的完全一样。入组后再改，就要按 protocol deviation 记录。
- 对开发：4 张图 + 4 个文件的颜色常量。没有逻辑改动。
- 对论文：方法部分描述陪伴者形象时，阿珍/阿伯写紫色系。
