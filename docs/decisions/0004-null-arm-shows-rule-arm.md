# 0004：还没分到组的用户显示规则组界面

> 补记（2026-10-04）：这个决定当时在对话里做出，代码已合并。按模板补写，内容以当时的讨论为准。

- 日期：2026-09-30
- 状态：已采纳
- 影响范围：phase_b × 两组
- 相关代码：`lib/core/arm/arm_scope.dart`

## 背景

分组可能失败（网络、服务器出错），用户会以 `arm` 为空的状态先用 App（`arm_assignment_scheme_v1.md` W5）。

## 决定

`arm` 为空时显示规则组界面，不调用 LLM；下次登录自动重试分组。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 显示 Hybrid 组 | 没有分组的人会用到 LLM，失败方向不安全 |
| 显示「请稍候」，不让用 | 当时没有讨论 |

## 后果

- 对研究：分到 A 组的人如果第一次分组失败，前几次使用看到的是 B 组界面。这段时间的数据怎么处理（计入还是剔除）还没定。
- 对开发：无。
