# 0053：老人打字时顶栏缩成一行，键盘收起再恢复

- 日期：2026-10-20
- 状态：提议中（待 Junyu 在真机上看过再定）
- 影响范围：pilot / phase_b × 两组（同一套页面，两组一样）
- 相关代码：分支 `claude/zealous-fermat-8rgqtg-keyboard`；`lib/shared/widgets/keyboard_compact.dart`、`lib/core/agents/companion_app_bar.dart`、`lib/core/feature_flags/remote_feature_flags.dart`

## 背景

Junyu 报告：老人打字时键盘升起，页面顶栏仍占原来的位置，输入框和对话看不全。量过：小手机（360×640）、App 最大字（1.30）、键盘约 300 像素时，顶栏 72 像素加状态栏 24 像素不动，聊天区只剩 99–155 像素，约 3–5 行字；一条四行的回复会被切掉一截。10/15 已把聊天列表改成「最新一条贴住输入框」，但顶栏没动。

## 决定

1. 新开关 `app_config/feature_flags.keyboardCompactHeaderEnabled`（**默认关**，只认布尔 `true`）。关着一切照旧。
2. 开着时，只要键盘打开（`MediaQuery.viewInsetsOf(context).bottom > 0`），老人会打字的页面的顶栏变成一行：高 72 → 48，标题字小一号（陪伴者页是小头像加名字，其他页是原标题）。左上角「今日傾到呢度」或返回键**原样保留**，一按就到。键盘一收起，顶栏恢复原样。
3. 聊天页键盘打开时自动回到最新一条消息。键盘开着时老人往上拖看旧消息，不会被拉回。
4. 通通文章问答页顶上那条「根據文章：…」跟顶栏一起收起，键盘收起再出现。
5. 不加新文字。危机和支援入口不在顶栏（安全检测弹出的支援页、危机页照旧），不受影响。安全检测（`lib/core/safety/`）没改。
6. 一个共用的写法（`keyboardCompactAppBar`、`KeyboardScrollToLatest`），所有陪伴者页面经 `companionAppBar` 一起用上，两组完全相同。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 键盘打开时整个顶栏藏起来 | 「今日傾到呢度」和返回键也会不见，还要另找地方放；只多 48 像素 |
| 顶栏缩到 40 像素以下 | 「今日傾到呢度」按钮本身 44 像素高，再矮按钮要缩小，老人难按 |
| 只改聊天页，不改表格页 | 同一个 App 有的页缩、有的页不缩，老人会觉得乱；表格页改动只有一行 |
| 同时把输入框改矮 | 不是这次的问题（顶栏）；输入框字大是为了老人看得清，要改另议 |

## 后果

- 对研究：两组同一套页面，界面对等不变；不改干预内容、不改测量。开了开关要记 changelog 生效日期。
- 对开发：一个新文件，10 个页面文件各改几行（另有两个规则组表格页经 `companionAppBar` 自动跟上）；开关关时页面和以前一模一样（有测试）。
- 对论文：不需要写（界面可用性改进，两组相同）。
