## T37 引导顺序和显示设定的两个修复（分支 `fix/onboarding-settings`，SPEC:C01、C19；现在可以开）

依据：W0 装机脚本 `docs/release/w0-install-script.md` 第六节第 2、3 项；登记前只显示等待页、登记后才开始（10/9 第 20 条）；阿珍/阿伯以登记时的选择为准（10/9 第 23 条 (4)）。

1. **登记后仍要做伙伴介绍**：现在 `ConsentGate` 只在 `ahJanAhBakVariant` 为空时显示「介紹三個夥伴」，登记会写入这个字段，所以“先登记后引导”时伙伴介绍、兴趣选择和 S5 使用建议整段被跳过。改为用一个独立的“引导已完成”标记判断。登记后进入引导时，「揀邊個陪你做人生回顧」那一屏预先选好登记时的配对；老人改选时照现有规则记改动日志，分析以登记值为准。“先引导后登记”的旧顺序也要照样能用。和 T21 的登记门一起测：门开着时，注册 → 等待页 → 登记 → 重开 App → 完整引导。
2. **显示设定要保存**：「顯示設定」的字体（標準／大／特大）、高对比，以及「通知」里的「安靜時段」「語音讀出內容」，现在只存在页面状态里，关掉 App 就回到默认。改为保存在本机（例如 `shared_preferences`），重开后保持。不改选项和文字。
3. 两组相同。没有新的老人看得到的文字。修复 1 放在开关 `app_config/feature_flags.onboardingAfterEnrollmentFix` 后面，默认开还是关写进报告由 Junyu 定；修复 2 是缺陷修复，不加开关。
4. 测试：两种顺序各走一遍；登记值与老人改选不同时有改动日志；字体、高对比、安静时段关掉 App 再开仍保持。
