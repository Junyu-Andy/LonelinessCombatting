# 0007：Phase B 的 Hybrid 组记忆强制开启，不能关

> 补记（2026-10-04）：这个决定当时在对话里做出，代码已合并。按模板补写，内容以当时的讨论为准。

- 日期：2026-09-30
- 状态：已采纳
- 影响范围：phase_b × Hybrid 组
- 相关代码：PR #25（`MemoryModes`、`memory.js inScope`）

## 背景

记忆 v1 原设计是用户自愿开启（opt-in）。决策 0001 把记忆定为 Hybrid 组干预的一部分，如果可以关，组内干预剂量就不一致。

## 决定

Phase B Hybrid 组全员使用 v1，设置里没有关闭开关；老人只能在「我記得嘅嘢」页面逐条删除。onboarding 第一页告知。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 默认开、可在设置里关 | 组内干预不一致 |
| 只给测试账号开 | 无法评估记忆的作用 |

## 后果

- 对研究：ICF 必须写明（负责人在改）；如果有人留在研究里但要求删除全部记忆，现在没有办法让服务器停止记新的，待定。
- 对开发：没有写 `meta/memory_config` 时 Hybrid 组两套记忆都没有，上线时必须写。
