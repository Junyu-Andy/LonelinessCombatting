# 0034：记忆分共享层和私有层，按陪伴者在服务器上过滤

- 日期：2026-10-10
- 状态：提议中（T31，PR 草稿；分层规则研究侧 10/9 第 15 条已定，下面的具体做法待负责人确认）
- 影响范围：phase_b × Hybrid 组；phase_a（T32 把 Phase A 换到服务器记忆 v1 之后）。规则组没有记忆，不受影响
- 相关代码：分支 `feat/memory-layers`（T31，SPEC:C05）

## 背景

服务器记忆 v1 是每人一个池，每条带写入它的陪伴者（`agent_id`）。共享靠策略 C：只有“称呼、家人、居住”三类给另外两位，其余都只给写它的陪伴者。研究侧 10/9 第 15 条定了新的分法：共享层多了“日常作息”和“喜好兴趣”；私有层写明是心事、健康、哀伤、回忆故事、待跟进。

## 决定

1. **两层**。每条事实、摘要、待跟进由服务器写 `layer`（`shared` / `private`）和 `sourceAgent`（听到的那位）。客户端不能写或改（Firestore 规则本来就只许老人把待确认改成已确认）。
2. **哪类归哪层**：
   - 共享：`name` 称呼、`family` 家人和身边的人、`living` 居住、`routine` 日常作息、`hobby` 兴趣、`preference` 其他喜好；
   - 私有：`health` 健康、`event` 重要事件，以及抽取 prompt v3 新加的 `feeling` 心事和情绪、`story` 回忆故事、`grief` 哀伤内容；
   - 摘要、待跟进一律私有；
   - 判为敏感的（健康类、模型标的、敏感词命中的），即使在共享类目也算私有。
3. **调用时在服务器过滤**：共享层给三位；私有层只给 `sourceAgent`；待跟进只由 `sourceAgent` 提起。抽取时模型看到的“现有事实”也按同样规则。开关打开后，旧的策略 A / C 都按这条规则；策略 B（老人关了共享同意，决策 0020）仍然什么都不共享。
4. **旧数据不迁移**。没有 `layer` 的条目读取时按第 2 条推算（以前的数据都是测试员的，10/9 第 18 条 (7)）。
5. **删除覆盖两层**。「唔好記住」本来就查所有陪伴者的条目（决策 0024），不变。设置里删一条时，除了决策 0024 已有的（来源会话的摘要、措辞完全相同的条目），再删：措辞去掉空格标点后相同的事实和跟进；同类目、同标题的事实（每位陪伴者各存一份私有副本的情况）；原文里含这条内容（至少 4 个字）的摘要。
6. **记忆剂量分层计**。`mem_injections` 每次记共享几条、私有几条、各来自哪位陪伴者，以及会话编号（App 传 `sessionId` 时；T25 之前是空）。
7. **抽取 prompt v3**（`functions/prompts/memory_extraction.v3.txt`）加三个私有类目，写清哪类共享、哪类私有。**不切换**，`meta/memory_config.extractionPrompt` 仍是 v2，PI 审过后由研究侧定日期。
8. **开关**：服务器 `meta/memory_config.layersEnabled`，App 设置页说明 S7 用 `app_config/feature_flags.memoryLayersNoticeEnabled`。都默认关，关时和现在完全一样。两个一起开。

## 考虑过的其他方案

| 方案 | 为什么没选 |
|---|---|
| 每位陪伴者各存一个池，共享层另存一份 | 要迁移数据、改「我記得嘅嘢」页面和删除脚本；现在一人一池加两个字段就够 |
| 层由模型在 prompt 里标 | 模型会标错；层决定谁看得到，必须由服务器按规则定 |
| 设置里删一条只删措辞完全相同的 | 私有层里每位陪伴者各存一份，措辞多半不同，会漏删 |
| 用策略 C 只加两类 | 策略 C 的摘要、待跟进规则和新定义一致，但不写 `layer` 就没法分层计剂量 |

## 后果

- 对研究：操纵定义里“记忆”分两层，剂量可以按层、按陪伴者分开报告。`event` 归私有、过去经历里提到家人的事（如“老公以前揸的士”）会按家人归共享，这两点要研究侧确认（T31 报告）。ICF 和入组口头说明用 S7。
- 对开发：`functions/memory.js`（分层、过滤、剂量、删除）、`functions/index.js`（传 `sessionId`）、新 prompt 文件、App 记忆页一张说明卡和一个远程开关。T30 的过程数据导出要读 `mem_injections` 的新字段。
- 对论文：方法部分描述记忆分层和过滤在服务器执行；局限部分写“同一件事”的判断是规则，可能漏删或多删。
