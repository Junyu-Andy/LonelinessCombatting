## 2. C07 行动计划提醒（`functions/reminders.js`，`functions/index.js` `dispatchReminders`）

| 项目 | 做法 |
|---|---|
| 发送方式 | 服务器定时函数 + FCM，发到 `users/{uid}/fcm_tokens` 里的每台手机。不用手机本地通知（要加原生依赖） |
| 时间与时区 | `*/15 8-21 * * *`，`Asia/Hong_Kong`。App 写的 `fireAt` 是不带时区的本地时间字符串，按香港时间读。晚上到时间的提醒第二天 08:00 发 |
| 不发 | 超时 12 小时以上（`skipped_stale`）；当天开了「今日休息」（`skipped_quiet_today`）；计划已删（`skipped_plan_missing`）或已回答（`skipped_followed_up`） |
| 失败重试 | 一台都没发成功 → 下次运行再试，最多 3 次，之后记 `failed`；没有手机令牌同样重试，之后记 `no_tokens` |
| 不重复 | 发送前用文档更新时间做条件写入「认领」；同一条最多发一次。运行中途崩溃的那条不再重发 |
| 记录 | 提醒文档写回 `delivered`、`dispatchStatus`、`dispatchAttempts`、`dispatchedAt` 等；发出后在 `users/{uid}/events` 记 `m7_reminder_sent` |
| 两组 | 不看分组，不调用 LLM |
| 文案 | 标题「陪住」（现有推送标题），内容「件事點呀？」（现有提醒标题，`action_loop_arm_a_page.dart:256`、`action_loop_arm_b_page.dart:92`）。**不发**计划原文 |

**开关**：`app_config/reminders.m7FollowupPushEnabled`，**默认关**（文档不存在 = 关）。可选参数 `staleHours`（默认 12）、`maxAttempts`（默认 3）。

测试 `functions/test/reminders_emulator_test.js`（模拟器，假 FCM）9 项通过：开关关时不动；两组都发且不含原文；香港时区；超时跳过；今日休息、已回答、已删跳过；失败重试 3 次后放弃；临时失败后成功；无令牌；已认领不重发。
