## 心情一行（5.1，两组相同）

花括号是变量。M5 的表情和字跟首页原来的五个表情一样（😔 好差、🙁 差、😐 麻麻地、🙂 幾好、😊 好好），时间是最近一次揀的时间。

| 编号 | 什么时候显示 | 文字 |
| --- | --- | --- |
| M1 | 今天还没答 | 你而家心情點？ |
| M2 | M1 旁边的小字按钮 | 遲啲先答 |
| M3 | 撳完表情后短暂显示（约 2 秒） | 記低咗 |
| M4 | 撳了 M2 之后，当天 | 今日心情：未答（撳一下答） |
| M5 | 已答 | 今日心情：{表情} {幾好}（{09:12}） |
| M6 | M5 下面的小字，撳了展开五个表情 | 而家有冇變？ |
| M7 | 当天第一次答完后，下面一行；撳过或做完 check-in 后不再显示 | 想同小欣講詳細啲？ |
| M8 | 之后再答而且和上一笔不同，取代 M7；撳过或下次打开后不再显示 | 心情好似唔同咗，想同小欣講下發生咩事？ |

## 从 M7、M8 进小欣聊天的开场（5.2，规则组用；Hybrid 组由 LLM 照同一意思说，LLM 失败时也用这一句）

M7 按刚揀的心情：好好 → O1，幾好 → O2，麻麻地 → O3，差 → O4，好差 → O5（5.2 用「好開心」至「好唔開心」五个说法，对应同一个 1–5 分）。M8 按和上一笔比：好咗 → C1，差咗 → C2。O4、O5、C2 之后，规则组用 SN1–SN4 回应（`check-in-chat.md`），其余用 SY1–SY6。

## 第一页问卷一行（5.5 W4、W5）

日期写法：`10月26日（星期日）`。剩余日数按还剩几个 24 小时算，最少 1：第一天晚上开放时是 3，最后一天是 1。第 4 周开 4 天（第 26 至 29 天），开放当晚是 4。

| 编号 | 用在哪里 | 文字 |
| --- | --- | --- |
| W4 | 第一页，未开放（或这一周已做完，显示下一次） | 下次問卷：{10月26日（星期日）}開，開咗之後三日內答都得。 |
| W5 | 第一页，开放中、还没做完 | 問卷開咗，仲有 {N} 日。 |
