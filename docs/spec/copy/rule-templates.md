## 规则

1. 小欣：老人填完每日签到后，按老人选的心情给一条。签到的心情必选。
2. 阿珍 / 阿伯：老人写完一段回忆后，按老人选的“講起呢段往事嘅心情”给一条。阿珍和阿伯用同一套文字。回忆的心情选填；没选心情时用通用模板 G-1（10/10 第 3 条 (2)）。
3. 哀伤内容（回忆里命中 `moderate_review` 的内容）不另写专用模板，用 Z5 一组（四条全用）（10/10 第 3 条 (3)）。
4. 老人写的内容命中需要危机处置的安全词时，不出模板，直接走安全流程（T15 已这样做）。
5. 同一位老人、同一位陪伴者，近几次不重复（T15 的 `recentWindow`）。
6. 心情五档：好開心、幾好、一般般、唔係幾好、好唔開心。
