# 每日 check-in 推送、每周问卷提醒、给 Junyu 的电邮（草稿）

结论：第 4 批的推送文字和电邮标题都在这里。两组文字完全相同，不由 LLM 生成。

- 来源：
  - P1、P2、E1：dev-tasks-1020b 第四节 5.3、5.5（工作台“待定稿文字”10/19 版）；
  - 每周问卷推送：dev-tasks-1020e 第二节 1 (4)、2 (2)（10/20 版，取代 1020b 的 W1–W3、W1-4–W3-4）。
- **草稿**：Junyu 在 PR 截图里定稿，定稿后改这里，再改代码。
- 开关：
  - P1、P2 跟 `app_config/feature_flags.checkInChatV2Enabled`；
  - 每周问卷推送和 E1 跟 `app_config/feature_flags.weeklyReminderV2Enabled`。
  - 默认关，关时一切照旧。
- 代码：`functions/push_copy.js`。`functions/test/push_copy_test.js` 逐字比对这份文件。
- 推送标题都是「陪住」。
- 第 1–3 周共用一套文字，`{N}` 由程序换成「一」「二」「三」。
