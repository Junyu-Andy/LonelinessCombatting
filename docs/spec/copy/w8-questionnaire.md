## 3. 沿用第 1–3 周每周问卷的框架文字（不是新字）

交接第二节 (2)：外框、按钮、状态文字同第 1–3 周每周问卷。下面这些字原样沿用，W8 没有改：

- 每部分页顶：「第 N 部分，共 5 部分」
- 每题：「第 i 題（共 n 題）」，按钮「上一題」「跳過呢題」
- 每部分最后：「答完喇，多謝你！撳「提交」就完成。」，按钮「提交」「上一題」
- 问卷页按钮「開始」「繼續」；每部分的状态「未開始」「未做完」「已完成」「已過時間」
- 可选问卷填完或「唔填喇」之后：「全部做完喇，多謝你！」，按钮「完成」
- 已交或已截止再打开：「呢份問卷已經完成或者已經截止，唔使再答。」
