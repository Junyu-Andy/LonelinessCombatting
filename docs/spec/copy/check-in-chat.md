# 小欣聊天窗口：对话式 check-in 和规则组小欣聊天（草稿）

结论：小欣卡片在两组都打开同一个聊天窗口。当天没做 check-in 就自动开始；问题文字、按钮和顺序两组完全相同，不由 LLM 生成。规则组的回应全部来自下面和 `rule-templates.md` 的模板，不调用 LLM。

- 来源：dev-tasks-1020b 第四节 5.2b、5.3（工作台“待定稿文字”10/19 版）。**草稿**：Junyu 在 PR 截图里定稿，定稿后改这里，再改代码。
- 开关：`app_config/feature_flags.checkInChatV2Enabled`（默认关；关时一切照旧）。
- 代码：`lib/features/context/data/check_in_chat_copy.dart`（问题、按钮、XG、R4a、R4b、SY0）、`lib/features/context/data/siu_yan_rule_chat_pool.dart`（SY1–SY6、SN1–SN4）。`test/final_copy_test.dart` 逐字比对这份文件。
- 回应一的规则组模板 X1–X5 在 `rule-templates.md`（按 Q1 尋日整體分档）。

## check-in 问题（两组相同）

Q0 中午前用「早晨」，中午 12:00 起把「早晨」换成「你好」。Q3b 只在 Q3 选「一啲小事」或「一件大事」时出。

| 编号 | 用在哪里 | 文字 | 按钮 |
| --- | --- | --- | --- |
| Q0 | 开场 | 早晨！想問下你尋日嘅情況，幾條就得。 | |
| Q1 | 第一题 | 尋日成日整體過得點？ | 好開心／幾好／一般般／唔係幾好／好唔開心／唔想答 |
| Q2 | 第二题 | 尋日有冇同人傾過偈？ | 冇／少少／幾多／好多 |
| Q3 | 第三题 | 尋日有冇咩特別事？ | 冇／一啲小事／一件大事 |
| Q3b | Q3 选了小事或大事 | 想講下係咩事嗎？打字講都得，唔講都得。 | 输入框；唔講住 |
| Q4 | 第四题，开放 | 今日有咩打算？想講就講，唔講都得。 | 输入框；唔講住 |
| Q5 | 两组；撳「好呀」打开现有的行动计划 | 想訂個小計劃嗎？ | 好呀／唔使喇 |
| Q6 | 结束 | 多謝你同我傾，聽朝再問候你。 | |

## 规则组的固定回应

| 编号 | 用在哪里 | 文字 |
| --- | --- | --- |
| XG | 回应一，Q1 选「唔想答」 | 多謝你話俾我知尋日嘅情況。 |
| R4a | 回应二，Q4 有答 | 好呀，今日就照你嘅打算慢慢嚟。 |
| R4b | 回应二，Q4 选「唔講住」 | 冇問題，今日慢慢諗都得。 |
| SY0 | 当天 check-in 已做完，再进小欣页的开场 | 今日 check-in 做咗喇，想再講啲咩都得。 |

Hybrid 组：回应一由 LLM 按 Q1 至 Q3 回一两句；Q4 有答时回应二由 LLM 最多提一两个去处或做法，不催促；Q4 选「唔講住」时用 R4b 这句固定文字，不调 LLM、不给建议（开发窗口的做法，待 Junyu 确认）。已做完 check-in 再进来时，开场一句由 LLM 说；LLM 失败时用 SY0。

## 规则组小欣聊天回应池

老人每发一句，小欣从下面轮换回一句，近 3 次不重复，不调用 LLM。命中安全词时不出模板，走安全流程。当天最近一笔心情是「唔係幾好」或「好唔開心」（`daily_mood` 1 或 2），或者从低落心情的开场（O4、O5、C2，第 3 批接入）进来时用 SN，否则用 SY。

| 编号 | 用在哪里 | 文字 |
| --- | --- | --- |
| SY1 | 一般回应 | 多謝你同我講，我喺度聽緊。 |
| SY2 | 一般回应 | 明白。你慢慢講，唔使急。 |
| SY3 | 一般回应 | 聽落你都有唔少嘢諗。想講多啲都得。 |
| SY4 | 一般回应 | 好呀，再講多少少俾我聽？ |
| SY5 | 一般回应 | 你講嘅我都聽到。今日記得飲多啲水，休息下。 |
| SY6 | 一般回应 | 收到。得閒隨時嚟搵我傾。 |
| SN1 | 心情低落时 | 聽落你而家唔係咁好受，我喺度陪你。 |
| SN2 | 心情低落时 | 多謝你肯講出嚟，唔使一個人頂住。 |
| SN3 | 心情低落时 | 慢慢嚟，想停一停都得。 |
| SN4 | 心情低落时 | 除咗同我講，如果有信得過嘅人，都可以搵佢哋傾下。 |
