# 第 3 批（T53 = D、T54 = E、T56 的 (2) = G (2)）：首页分两页、心情一行、M7／M8 进小欣聊天、问卷一行、做啲嘢工具图

日期：2026-10-20。分支 `claude/zealous-fermat-8rgqtg-batch3`（从第 2 批 `claude/zealous-fermat-8rgqtg-batch2` @ `8e39e5e` 开，PR 草稿）。范围：1020 第 D 节、第 E 节、第 G 节 (2)；1020b 第二节 (1)(2)；Junyu 10/19 的做啲嘢定稿图。不含 G (1)(3) 推送和电邮（第 4 批），服务器只加了一个提示词文件。

## 结论

- 做完了。新行为全部在两个远程开关后面：`app_config/feature_flags.homeLayoutV2Enabled` 和 `moodRowV2Enabled`，**默认关**，只认布尔 `true`；关时首页、搵人傾页、做啲嘢页一字不变。10/21 构建按 1020 第 3 节两个都设为开。
- 开关开时：第一页「睇今日」只放今天的事；三位伙伴搬到第二页「搵人傾」；**邀请卡两页都有**，从第一页开始的会话结束回到第一页就看到，下次打开 App 也看到。
- 心情一行**没有任何弹窗**：每日心情弹窗、Hybrid 组独有的小条和对话框都不再出现。状态表五格（未答、跳过、已答、再答相同、再答不同）都做了，两组相同。
- M7、M8 进**小欣聊天**（不是 check-in）：规则组小欣用 O1–O5、C1、C2 开场，之后照第 2 批的回应池，**全程零 LLM 调用**（测试里装了“一叫就报错”的假模型）；Hybrid 组由 LLM 开场，用新提示词 `siu_yan.v4`（= v3 + 一节，v3 不动）。
- 1020b 第二节两条做成“不可达”并有测试：心情一行开着时 `homeMoodOpensCheckInEnabled` 怎么设都没用；两页版面开着时旧的 `briefPrHomeBannerEnabled` 横幅永远不出，第一页只有一张卡。
- 全部 Flutter 测试（六套）、相关 Functions 测试（单元 + 模拟器）通过；`flutter analyze` 0 个 error，提示条数和第 2 批一样（93，都是原有的）。
- 老人看到的文字全部是草稿，等你在截图里定。D1–D4 四句是 1020 第 D 节提到、但第四节没有给文字的，由开发窗口先写。

## 1. 老人会看到什么（开关开时，两组相同）

### 1.1 第一页「睇今日」（从上到下）

1. 问候（原来的问候色块，日期和「下午好，名字」）。
2. 心情一行（见 1.3），放在问候色块里。
3. 小标题「今日要做嘅事」（D1），下面每项一行，有才出现：
   - **同小欣 check-in**（D2）：每天都有。没做是空心圆，撳了进小欣页并开始当天 check-in；做完变成打勾，不能撳。连续 3 天没做时，这一行下面多一句「幾日冇見你。快速 check-in 一分鐘就完，冇壓力。」（D3，原来横幅的两句合成一句），不再另出横幅。
   - **Brief PR 邀请卡**：就是现有的 `BriefPrCardHost`，聊完即出和下次补问都在这里，有「好呀」「今次唔評」。
   - **问卷一行**（见 1.5）。
   - **行动计划跟进**：现有的「今日小行動」卡，有计划才出。
   - 还有一张现有的“待办问卷”卡（`PendingPromptsBanner`），只在有 Phase A 项目或旧排程时才出；问卷一行出现时它不再显示每周问卷，免得两张。
4. 大按钮「去搵人傾」（D4），撳了切到第二页（等于点底部第二个 tab）。
5. 本周小结一行（不变）。
6. 危机支援卡（不变）。

拿走的：三位伙伴卡、继续聊天卡、第一周提示（搬到第二页）、三个工具捷径、每日心情弹窗、三天未做横幅、旧的「今日仲未做 check-in」小条。

### 1.2 第二页「搵人傾」

### 1.3 心情一行（状态表）

| 状态 | 老人看到 | 撳了会怎样 |
|---|---|---|
| 未答 | M1「你而家心情點？」、五个表情、右边小字 M2「遲啲先答」 | 撳表情 → 已答；撳 M2 → 跳过 |
| 跳过 | M4「今日心情：未答（撳一下答）」，当天不再自动展开（重开 App 也一样） | 撳 M4 → 展开五个表情 |
| 已答 | M5「今日心情：🙂 幾好（09:30）」；刚撳完约 2 秒显示 M3「記低咗」，之后是 M6「而家有冇變？」；下面一行 M7「想同小欣講詳細啲？」 | 撳 M6 → 展开五个表情；撳 M7 → 小欣聊天 |
| 再答相同 | M5 时间更新，M7 仍在 | 同上 |
| 再答不同 | M5 换成新的；M8「心情好似唔同咗，想同小欣講下發生咩事？」取代 M7 | 撳 M8 → 小欣聊天 |

- M7：撳过、当天做完 check-in、或被 M8 取代后，当天不再出现。
- M8：撳过就消失；App 退到后台或关掉再开也消失。
- 两者都要 `checkInChatV2Enabled` 也开着（小欣聊天窗口在那个开关后面），否则不出现。
- 五个表情和下面的字沿用首页原来的：😔 好差、🙁 差、😐 麻麻地、🙂 幾好、😊 好好（见第 8 节第 3 条）。
- 两组都**没有**任何小条、对话框或弹窗。

### 1.4 M7、M8 进小欣聊天

进去直接是聊天，不开始 check-in（check-in 仍在第一页那一行）。

| 入口 | 规则组开场（不调 LLM） | 之后规则组回应 | Hybrid 组 |
|---|---|---|---|
| M7，好好 | O1 見你而家心情咁好，我都開心！有咩好事，講俾我聽下？ | SY1–SY6 轮换 | LLM 开场：先承认心情，再用一条开放式问题问发生咩事 |
| M7，幾好 | O2 心情幾好，好呀。今日有咩想同我傾？ | SY | 同上 |
| M7，麻麻地 | O3 一般般都唔緊要。有咩想講，慢慢講。 | SY | 同上 |
| M7，差 | O4 聽到你心情唔係幾好。想講下發生咩事嗎？我喺度聽。 | **SN1–SN4** | 同上，语气放慢 |
| M7，好差 | O5 你而家好唔開心，辛苦你喇。想講就講，唔想講陪下你都得。 | **SN** | 同上 |
| M8，好咗 | C1 心情好咗喎！發生咗咩好事呀？ | SY | LLM 开场，提到变化 |
| M8，差咗 | C2 心情好似差咗啲，發生咗咩事？想講就慢慢講。 | **SN** | 同上 |

- Hybrid 组：App 只把「而家揀嘅心情」和（M8 时）「之前揀嘅心情、好咗定差咗」放进 `[開場·心情]` 块，不放老人写过的任何字。LLM 失败时用同一句 O／C 文字。之后照旧 LLM 聊天。
- 安全：之后打的每一句两组都照第 2 批的安全流程，命中不出模板。
- 会话：这是“自由聊天”（moduleId `siu_yan_chat`），≥3 条有回复才算有效，有效才有邀请卡。

### 1.5 问卷一行（G (2)）

只在研究周排程开着时出现（`app_config/phase_b.weeklyScheduleV2Enabled`、Phase B 构建、已登记）；没开时旧的问卷卡照旧。

- 开放中、还没做完：W5「問卷開咗，仲有 3 日。」撳了打开每周问卷（和旧卡同一个页面）。
- 没开放，或这一周做完了：W4「下次問卷：10月21日（星期三）開，開咗之後三日內答都得。」不能撳。
- 第 7 周之后不再出现。
- 剩余日数 = 还剩几个 24 小时，向上取整，最少 1：第 1–3、5–7 周开放当晚是 3，最后一天白天是 1；第 4 周（第 26 至 29 天）开放当晚是 4。
