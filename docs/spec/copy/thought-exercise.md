## 2. 删掉的字

- 第一次打开时的提示条「呢度可以畀你睇返自己最近嘅心情同諗法。慢慢嚟，唔趕。」
- 旧第一题「嗰陣係咩情況？」、旧第四题「一個令呢個諗法可能成立嘅理由」。
- 前後對照页旧的「依家再 rate 一下你嘅感覺……」和「依家有幾強烈？撳一個數字（1–10）」两句；现在只用上面 TE-after 一句说明。右边的「依家」改成「而家」。

## 3. 哪些必填

- 必填：第一题（那句话）、第二题（表情和 1 至 10 的数字）。没填好「繼續」按不了。
- 可以留空：第三题、第四题。
- 前後對照页照旧：要选一个数字才能按「完成」。

## 4. 从小欣的邀请进来

Hybrid 组老人在邀请卡上按「好，試下」，练习页的第一题已经填好老人头先讲的那一整句（不截短），老人可以改。从「做啲嘢」进来（两组都一样）就是空白的。
