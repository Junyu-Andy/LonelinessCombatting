# Flutter 3.44.1 真机走查（Android，两组）

> 2026-10-20 第一版（1020p 第一节，决策 0067）。

## 结论

- 这次只换了开发工具的版本（Flutter 3.35.3 → 3.44.1）。**老人看到的、做的应该完全一样，两组也一样。**
- 电脑上能做的都做了：全部自动测试、10 组截图逐个像素比对。**真机这一轮只看一件事：和旧版本一样不一样。** 不测新功能。
- 最要紧的是第二节：**新包直接覆盖旧包，不卸载，登录还在。**
- 两组各走一遍，大约 60–90 分钟。每一步截一张图。
- 有任何地方和旧版不一样：截图，写下步骤号，发给开发窗口。那就先不合并这个 PR，冻结构建留在 3.35.3。

## 一、准备

1. **一部 Android 手机**（Android 10 或以上；最好是参与者常用的那种）。
2. **两个 APK**，都在 GitHub → **Actions** → **Build APK** → **Run workflow**，版本选 `phase_b_templates`：

   | 包 | 分支 | 用来做什么 |
   |---|---|---|
   | 旧包（3.35.3） | `claude/zealous-fermat-8rgqtg-freeze-1021`，**在合并本 PR 之前**打 | 先装在手机上 |
   | 新包（3.44.1） | `claude/zealous-fermat-8rgqtg-flutter344` | 覆盖安装 |

   - 两次运行都要成功。打开运行页面的 **Summary**，「APK 签名」那段的**证书 SHA-256 两次必须一模一样**。不一样就停，不要装。
   - 运行失败、提示 `Release signing secrets missing`：固定签名钥匙还没放进 GitHub，先按 `docs/release/android-signing.md` 第一节做。
   - 下载：运行页面底部 **Artifacts** → 下载 zip → 解压得到 `app-release.apk`。改名为 `旧-3353.apk`、`新-3441.apk`，免得混。
3. **两个合成测试账号**，都是测试员（`isTester: true`，危机测试不会发告警邮件）：一个 Hybrid 组，一个规则组。名字、资料全部用假的。**不要用参与者账号。**
4. 控制台开关：保持和冻结构建一样，**不要为了这次测试去改**。
5. 截图命名：`组别-步骤号`，例如 `HY-03.png`（Hybrid）、`RB-03.png`（规则组）。

## 二、覆盖安装（最重要，先做）

| 步骤 | 做什么 | 应该看到 |
|---|---|---|
| 0.1 | 手机上装**旧包**，用 Hybrid 测试账号登录，走到首页 | 首页正常。截图 `HY-0.1` |
| 0.2 | 「自己」→「關於本App／常見問題／私隱」，看版本那一行，记下来 | 截图 `HY-0.2` |
| 0.3 | **不要卸载**。直接点开**新包**，按「更新」或「安装」 | 直接装上。**不能**出现「与已安装的应用冲突」「签名不一致」「应用未安装」 |
| 0.4 | 打开 App | **还是登录状态**，不用重新登录；首页的资料还在。截图 `HY-0.4` |
| 0.5 | 再看同一页的版本那一行 | 版本号和 0.2 一样（这次没改版本号；下面几行的编译信息可以不同）。截图 `HY-0.5` |

0.3 装不上：**停下，截图，告诉开发窗口。不要卸载重装**——装不上说明签名钥匙不一样，参与者那边也会装不上。

## 三、逐步走查

Hybrid 账号走一遍；然后「自己」→「個人資料」→ 登出，换规则组账号登录，再走一遍。每一步看三样：**文字、颜色、按钮位置**和旧版一样；**换页**时页面是「放大淡入」（和旧版一样，不是从旁边滑进来）；没有闪退、没有卡住。

| 步骤 | 做什么 | 应该看到（和旧版一样） | 两组的差别（本来就有） |
|---|---|---|---|
| 1 登录 | 登出再登录一次 | 登录页、输入框、键盘都正常；登录后到首页 | 无 |
| 2 等待页 | 用一个**新注册、研究员还没录入**的测试账号登录（没有这种账号就跳过，写「跳过」） | 停在「請等研究人員同你講解，再繼續。」，下不去 | 无 |
| 3 首页两页 | 第一页「睇今日」从上滑到下；再换到第二页「傾偈」 | check-in 一行、问卷一行、小行动一行、卡片和颜色都和旧版一样；浅色按钮和提示框上的**深色字**没有变浅 | 无 |
| 4 小欣 check-in | 「同小欣 check-in」，从第一题答到最后 | 选项按钮排成整齐的格子；心情按钮五个一样大；答完回到首页 | Hybrid 有 AI 回应；规则组是固定回应 |

| 9 Brief PR | 做完 step 4 后，首页出现 Brief PR 邀请卡时点开，答完 | 7 个点排成一行，下面三个说明；最后一题上方的提示正常 | 无（没出现就写「没出现」，不算不过） |
| 10 危机页 | 在小欣聊天里打合成测试句：「我真係想死，今晚就想了結自己。」 | **立即**打开紧急求助页，热线列表一样。按一个拨号按钮：拨号界面弹出、号码已填好，**看到号码就挂断，不要拨出**。回到聊天，有一条固定安全消息和「打開緊急求助頁」按钮 | 两组完全一样；Hybrid 这一句没有 AI 回复 |
| 11 常見問題 | 「自己」→「關於本App／常見問題／私隱」→「常見問題」，六条全部点开 | 页顶一句、六条问题和图标、答案都在；号码只有 18111 和 999 | 无 |

| 13 返回键 | 在三四个页面用手机的返回手势或返回键 | 回到上一页，动画是「放大淡入」；不会突然退出 App | 无 |
